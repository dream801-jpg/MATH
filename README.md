## 다시풀기

- [다시풀기 접속](https://dream801-jpg.github.io/MATH/dasi/)
- [앱 소스와 실행 안내](tutor-worksheet/README.md)

다시풀기 앱의 소스는 `tutor-worksheet` 폴더, 게시용 빌드 결과는 `dasi` 폴더에 있습니다. 소스를 고친 뒤 `PAGES_BASE_PATH=/MATH/dasi` 로 빌드해 `out` 폴더 내용을 `dasi`에 덮어쓰면 됩니다. 기존 과외 일정과 학습 자료는 그대로 유지합니다.
