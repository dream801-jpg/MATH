정답 및 풀이 · 채점 기준 (2회)

채점 기준은 학교 기준이 아니라 연습용 예시입니다. "왜 그렇게 되는지"를 한 줄씩 쓰는 습관이 만점의 핵심입니다.

1. 삼각비의 개념  1-1) AB : BC : CA = 8 : 15 : 17  /  1-2) $\dfrac{23}{17}$, $1$

① 변의 위치 — $\angle B = 90^\circ$ 이므로 빗변은 $\overline{AC}$ 이다. $\angle C$ 에서 보면 마주 보는 변은 $\overline{AB}$, 이웃한 변은 $\overline{BC}$ 이다.
② 두 변 정하기 — $\tan C = \dfrac{\overline{AB}}{\overline{BC}} = \dfrac{8}{15}$ 이므로 $\overline{AB} = 8k$, $\overline{BC} = 15k$ ($k > 0$) 로 놓는다.
③ 빗변 — 피타고라스 정리에 의해 $\overline{AC} = \sqrt{(8k)^2 + (15k)^2} = \sqrt{289k^2} = 17k$
④ 가장 간단한 자연수의 비 — $k = 1$ 로 하면 $\overline{AB} = 8$, $\overline{BC} = 15$, $\overline{CA} = 17$
답안 그림 예시 — ∠B에 직각 표시, 세 변 8, 15, 17
⑤ 1-2) — $\sin A = \dfrac{\overline{BC}}{\overline{AC}} = \dfrac{15}{17}$, $\cos A = \dfrac{\overline{AB}}{\overline{AC}} = \dfrac{8}{17}$ 이므로 $\sin A + \cos A = \dfrac{23}{17}$
$\tan A = \dfrac{\overline{BC}}{\overline{AB}} = \dfrac{15}{8}$ 이므로 $\tan A \times \tan C = \dfrac{15}{8} \times \dfrac{8}{15} = 1$
채점 요소배점
∠C 기준으로 AB(대변), BC(이웃변)를 찾아 AB : BC = 8 : 15를 세움1
피타고라스 정리로 AC = 17을 구하는 과정1
그림에 직각 표시(∠B)와 세 변 8, 15, 17을 모두 표시1
$\sin A + \cos A = \dfrac{23}{17}$ / $\tan A \times \tan C = 1$ (각 1점)2
⚡ 감점 함정: 조건이 ∠A가 아니라 ∠C에 대해 주어졌습니다. 기준 각이 바뀌면 "마주 보는 변"도 바뀝니다. 직각삼각형의 두 예각 A, C에 대해 $\tan A \times \tan C = 1$ 은 항상 성립합니다(검산용).

2. 특수각의 삼각비  $2\sqrt{2}$

① 각의 크기 — 삼각형의 세 내각의 합은 $180^\circ$ 이므로 (비의 합 $1+1+2 = 4$)
$\angle A = \angle B = 180^\circ \times \dfrac{1}{4} = 45^\circ$,   $\angle C = 180^\circ \times \dfrac{2}{4} = 90^\circ$
② 값 대입 — $\tan 45^\circ = 1$, $\sin 90^\circ = 1$, $\cos 45^\circ = \dfrac{\sqrt{2}}{2}$, $\cos 90^\circ = 0$
③ 계산 — $\dfrac{1 + 1}{\frac{\sqrt{2}}{2}} - 0 = 2 \times \dfrac{2}{\sqrt{2}} = \dfrac{4}{\sqrt{2}} = \dfrac{4\sqrt{2}}{2} = 2\sqrt{2}$
채점 요소배점
내각의 합 180°를 근거로 세 각 45°, 45°, 90°를 구함2
네 개의 삼각비 값을 정확히 대입 (하나라도 틀리면 1점)2
분모를 유리화하여 $2\sqrt{2}$ (유리화하지 않으면 감점)1
⚡ 감점 함정: 분모에 $\dfrac{\sqrt{2}}{2}$ 가 있으면 "역수를 곱한다"로 바꾸세요. 답 $\dfrac{4}{\sqrt{2}}$ 에서 멈추면 감점입니다. $\cos 90^\circ = 0$ 을 1로 쓰는 실수도 자주 나옵니다.

3. 예각의 삼각비의 값  3-1) $\cos a = \dfrac{12}{13}$, $\tan a = \dfrac{5}{12}$  /  3-2) $\dfrac{240}{169}$  /  3-3) $\dfrac{125}{312}$

① 기준 삼각형 — 점 A에서 $x$축에 내린 수선의 발을 H라 하면, 직각삼각형 OHA에서 $\overline{OA} = 1$ 이므로
$\sin a = \dfrac{\overline{AH}}{\overline{OA}} = \overline{AH} = \dfrac{5}{13}$
② 3-1) — $\overline{OH} = \sqrt{1^2 - \left(\dfrac{5}{13}\right)^2} = \sqrt{\dfrac{144}{169}} = \dfrac{12}{13}$ 이므로
$\cos a = \dfrac{\overline{OH}}{\overline{OA}} = \dfrac{12}{13}$,   $\tan a = \dfrac{\overline{AH}}{\overline{OH}} = \dfrac{5}{13} \div \dfrac{12}{13} = \dfrac{5}{12}$
③ 3-2) — 각 변이 좌표축에 평행하므로 직사각형은 두 좌표축에 대하여 대칭이고,
A$\left(\dfrac{12}{13}, \dfrac{5}{13}\right)$, C$\left(-\dfrac{12}{13}, -\dfrac{5}{13}\right)$ 이다.
가로 $= 2 \times \dfrac{12}{13} = \dfrac{24}{13}$, 세로 $= 2 \times \dfrac{5}{13} = \dfrac{10}{13}$ → 넓이 $= \dfrac{24}{13} \times \dfrac{10}{13} = \dfrac{240}{169}$
④ 3-3) — 직각삼각형 OET에서 $\overline{OE} = 1$ 이므로 $\overline{ET} = \tan a = \dfrac{5}{12}$
△CET에서 밑변을 $\overline{ET}$ (직선 $x = 1$ 위)로 보면, 높이는 점 C와 직선 $x = 1$ 사이의 거리이므로
높이 $= 1 + \dfrac{12}{13} = \dfrac{25}{13}$
넓이 $= \dfrac{1}{2} \times \dfrac{5}{12} \times \dfrac{25}{13} = \dfrac{125}{312}$
채점 요소배점
3-1) OA = 1인 직각삼각형에서 $\cos a$, $\tan a$ (각 1점)2
3-2) 가로 $\dfrac{24}{13}$, 세로 $\dfrac{10}{13}$ 을 근거와 함께 구하고 넓이 $\dfrac{240}{169}$2
3-3) $\overline{ET} = \tan a$ 와 높이 $\dfrac{25}{13}$ 을 밝히고 넓이 $\dfrac{125}{312}$1
⚡ 핵심: 기울어진 삼각형은 세로 선분 ET를 밑변으로 잡으면 높이가 "$x$좌표의 차"가 되어 쉽게 구해집니다. C의 $x$좌표가 음수이므로 거리는 $1 + \dfrac{12}{13}$ 입니다. (참고: C, O, A, T는 한 직선 위에 있습니다.)

4. 원과 현  4-2) 반지름 $10\,\text{cm}$

4-1) 모범 문장
원에서 현의 수직이등분선은 그 원의 중심을 지난다. (따라서 직선 CM은 중심 O를 지난다.)
① 길이 정리 — 직선 CM은 현 AB의 수직이등분선이므로 $\overline{AM} = \dfrac{1}{2}\overline{AB} = 8\,\text{cm}$ 이고, 4-1)에 의해 세 점 C, M, O는 한 직선 위에 있다.
② 식 세우기 — 반지름을 $r\,\text{cm}$ 라 하면 $\overline{OA} = \overline{OC} = r$, $\overline{OM} = \overline{OC} - \overline{CM} = r - 4$
직각삼각형 OAM에서 피타고라스 정리에 의해 $r^2 = 8^2 + (r - 4)^2$
③ 풀기 — $r^2 = 64 + r^2 - 8r + 16$ → $8r = 80$ → $r = 10$   따라서 반지름은 $10\,\text{cm}$
채점 요소배점
4-1) "현의 수직이등분선은 원의 중심을 지난다" 문장2
4-2) AM = 8, OM = r − 4로 놓고 피타고라스 식을 세움2
4-2) 식을 풀어 반지름 10 cm (단위 포함)1
⚡ 감점 함정: OM을 4로 착각하지 마세요. 4 cm는 CM(원 위의 점 C까지)이고, OM은 $r - 4$ 입니다. 깨진 접시나 원 모양 바퀴의 반지름 구하기가 모두 이 유형입니다.

5. 삼각비의 활용  약 $35.4\,\text{m}$

① 그림 해석 — 등대는 수면에 수직이므로 △ABD, △ABC는 모두 $\angle A = 90^\circ$ 인 직각삼각형이고, $\overline{AB} = 30\,\text{m}$ 는 ∠B에 이웃한 변이다. 이번에는 배가 D에서 C로 등대에서 멀어졌다(∠B가 커짐).
② 처음 위치 — △ABD에서 $\overline{AD} = 30 \tan 35^\circ = 30 \times 0.7002 = 21.006\,(\text{m})$
③ 20초 후 위치 — △ABC에서 $\overline{AC} = 30 \tan 62^\circ = 30 \times 1.8807 = 56.421\,(\text{m})$
④ 이동거리 — $\overline{DC} = \overline{AC} - \overline{AD} = 56.421 - 21.006 = 35.415\,(\text{m})$ → 반올림하여 35.4 m
채점 요소배점
∠A = 90°를 밝히고 tan를 써야 하는 이유(AB가 이웃한 변)를 보임1
AD = 30 tan 35° = 21.006 m1
AC = 30 tan 62° = 56.421 m1
멀어졌으므로 DC = AC − AD 임을 밝힘1
반올림하여 35.4 m (단위 포함)1
⚡ 감점 함정: 1회와 달리 배가 멀어지는 경우입니다. "처음" 위치가 어디인지 그림에서 먼저 확인하고, 큰 값에서 작은 값을 빼세요. 각이 커질수록 배는 등대에서 멀리 있습니다.
