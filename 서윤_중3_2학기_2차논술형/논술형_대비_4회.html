정답 및 풀이 · 채점 기준 (4회 · 실전 리허설)

채점 후 감점된 문항은 해당 회차(1~3회)의 같은 번호를 다시 풀어 보세요. 걸린 시간도 문항별로 적어 두면 좋습니다.

1. 삼각비의 개념  1-1) AB : BC : CA = 4 : 3 : 5  /  1-2) $\cos C = \dfrac{3}{5}$, $\tan C = \dfrac{4}{3}$

① 조건 정리 — $5\sin A - 3 = 0$ 에서 $\sin A = \dfrac{3}{5}$
② 두 변 정하기 — $\angle B = 90^\circ$ 이므로 빗변은 $\overline{AC}$ 이고, $\sin A = \dfrac{\overline{BC}}{\overline{AC}} = \dfrac{3}{5}$ 이므로 $\overline{BC} = 3k$, $\overline{AC} = 5k$ ($k > 0$)
③ 나머지 변 — 피타고라스 정리에 의해 $\overline{AB} = \sqrt{(5k)^2 - (3k)^2} = 4k$ → $k = 1$ 로 하면 $\overline{AB} = 4$, $\overline{BC} = 3$, $\overline{CA} = 5$
답안 그림 예시 — ∠B에 직각 표시, 세 변 4, 3, 5
④ 1-2) — ∠C에서 보면 이웃한 변은 $\overline{BC}$, 마주 보는 변은 $\overline{AB}$ 이므로
$\cos C = \dfrac{\overline{BC}}{\overline{AC}} = \dfrac{3}{5}$,   $\tan C = \dfrac{\overline{AB}}{\overline{BC}} = \dfrac{4}{3}$
채점 요소배점
식을 정리해 $\sin A = \dfrac{3}{5}$, BC : AC = 3 : 5를 세움1
피타고라스 정리로 AB = 4를 구하는 과정1
그림에 직각 표시(∠B)와 세 변 4, 3, 5를 모두 표시1
$\cos C = \dfrac{3}{5}$ / $\tan C = \dfrac{4}{3}$ (각 1점)2
⚡ 점검: 조건이 식 꼴로 나와도 먼저 "$\sin A = $ ○" 꼴로 정리하면 1회와 같은 문제가 됩니다. $\sin A = \cos C$ 인지 확인하면 검산이 됩니다.

2. 특수각의 삼각비  $\dfrac{\sqrt{6} - 1}{2}$

① 각의 크기 — 삼각형의 세 내각의 합은 $180^\circ$ 이므로 (비의 합 $3+4+5 = 12$)
$\angle A = 180^\circ \times \dfrac{3}{12} = 45^\circ$,   $\angle B = 180^\circ \times \dfrac{4}{12} = 60^\circ$,   $\angle C = 180^\circ \times \dfrac{5}{12} = 75^\circ$ (식에 쓰이지 않음)
② 값 대입 — $\sin 60^\circ = \dfrac{\sqrt{3}}{2}$, $\cos 45^\circ = \dfrac{\sqrt{2}}{2}$, $\tan 45^\circ = 1$, $\cos 60^\circ = \dfrac{1}{2}$
③ 계산 — $\dfrac{\sqrt{3}}{2} \div \dfrac{\sqrt{2}}{2} - 1 \times \dfrac{1}{2} = \dfrac{\sqrt{3}}{\sqrt{2}} - \dfrac{1}{2} = \dfrac{\sqrt{6}}{2} - \dfrac{1}{2} = \dfrac{\sqrt{6} - 1}{2}$
채점 요소배점
내각의 합 180°를 근거로 ∠A = 45°, ∠B = 60°를 구함2
네 개의 삼각비 값을 정확히 대입 (하나라도 틀리면 1점)2
분모를 유리화하여 $\dfrac{\sqrt{6} - 1}{2}$1
⚡ 점검: $\dfrac{\sqrt{3}}{\sqrt{2}} = \dfrac{\sqrt{3} \times \sqrt{2}}{\sqrt{2} \times \sqrt{2}} = \dfrac{\sqrt{6}}{2}$ 의 유리화 과정을 한 줄 써 주세요. 75°는 특수각이 아니므로 식에 없음을 확인하는 것도 좋습니다.

3. 예각의 삼각비의 값  3-1) $\sin a = \dfrac{3}{5}$, $\cos a = \dfrac{4}{5}$  /  3-2) $\dfrac{12}{25}$  /  3-3) $\dfrac{3}{40}$

① 3-1) — 점 A에서 $x$축에 내린 수선의 발을 H라 하면 직각삼각형 OHA에서 $\tan a = \dfrac{\overline{AH}}{\overline{OH}} = \dfrac{3}{4}$ 이므로 $\overline{OH} = 4k$, $\overline{AH} = 3k$ 로 놓는다.
$\overline{OA} = \sqrt{(4k)^2 + (3k)^2} = 5k = 1$ 이므로 $k = \dfrac{1}{5}$ → $\overline{OH} = \dfrac{4}{5}$, $\overline{AH} = \dfrac{3}{5}$
$\sin a = \dfrac{\overline{AH}}{\overline{OA}} = \dfrac{3}{5}$,   $\cos a = \dfrac{\overline{OH}}{\overline{OA}} = \dfrac{4}{5}$
② 3-2) — 직사각형의 각 변이 좌표축에 평행하므로 직사각형은 $x$축에 대하여 대칭이고, A$\left(\dfrac{4}{5}, \dfrac{3}{5}\right)$, D$\left(\dfrac{4}{5}, -\dfrac{3}{5}\right)$ 이므로 $\overline{AD} = \dfrac{6}{5}$ 이고, O에서 $\overline{AD}$ 까지의 거리는 $\dfrac{4}{5}$
넓이 $= \dfrac{1}{2} \times \dfrac{6}{5} \times \dfrac{4}{5} = \dfrac{12}{25}$
③ 3-3) — $\overline{OE} = 1$ 이므로 $\overline{ET} = \tan a = \dfrac{3}{4}$, A에서 직선 $x = 1$ 까지의 거리는 $1 - \dfrac{4}{5} = \dfrac{1}{5}$
넓이 $= \dfrac{1}{2} \times \dfrac{3}{4} \times \dfrac{1}{5} = \dfrac{3}{40}$
채점 요소배점
3-1) OA = 1을 이용해 $\sin a$, $\cos a$ (각 1점)2
3-2) AD = $\dfrac{6}{5}$, 높이 $\dfrac{4}{5}$ 를 밝히고 넓이 $\dfrac{12}{25}$2
3-3) ET = tan a, 높이 $\dfrac{1}{5}$ 로 넓이 $\dfrac{3}{40}$1
⚡ 점검: tan가 주어지면 "$\overline{OA} = 1$"이 되도록 비례상수 $k$를 정하는 것이 핵심입니다. 3-3)은 2회 3-3)과 같은 방법(세로 선분 ET를 밑변으로)입니다.

4. 원과 현  4-2) $\overline{AB} = 8\sqrt{3}\,\text{cm}$

4-1) 모범 문장
원의 중심에서 현에 내린 수선은 그 현을 이등분한다. (따라서 $\overline{AM} = \overline{BM}$)
① 직각삼각형 — $\overline{OM} \perp \overline{AB}$ 이므로 △OAM은 $\angle OMA = 90^\circ$ 인 직각삼각형이고, $\angle AOM = 60^\circ$ 의 대변이 $\overline{AM}$ 이다.
② 삼각비 — $\sin 60^\circ = \dfrac{\overline{AM}}{\overline{OA}}$ 이므로 $\overline{AM} = 8 \sin 60^\circ = 8 \times \dfrac{\sqrt{3}}{2} = 4\sqrt{3}\,(\text{cm})$
③ 현의 길이 — 4-1)에 의해 $\overline{AB} = 2\overline{AM} = 8\sqrt{3}\,(\text{cm})$
채점 요소배점
4-1) "중심에서 현에 내린 수선은 현을 이등분" 문장2
4-2) △OAM에서 $\sin 60^\circ$ 로 AM = $4\sqrt{3}$ cm2
4-2) 4-1)을 근거로 AB = $8\sqrt{3}$ cm (단위 포함)1
⚡ 점검: 길이가 하나(OA)와 각만 주어지면 피타고라스 대신 삼각비를 씁니다. OM = $8\cos 60^\circ = 4$ 를 먼저 구한 뒤 피타고라스로 AM을 구해도 맞습니다.

5. 삼각비의 활용  약 $51.2\,\text{m}$

① 각 옮기기 — ∠ABD, ∠ABC는 수평선 BA에서 잰 각이다. $\overline{BA} \parallel \overline{HC}$ 이므로 엇각으로 $\angle BDH = 55^\circ$, $\angle BCH = 20^\circ$
△BHD에서 $\angle HBD = 90^\circ - 55^\circ = 35^\circ$, △BHC에서 $\angle HBC = 90^\circ - 20^\circ = 70^\circ$
② 처음 위치 — $\overline{HD} = 25 \tan 35^\circ = 25 \times 0.7002 = 17.505\,(\text{m})$
③ 20초 후 위치 — $\overline{HC} = 25 \tan 70^\circ = 25 \times 2.7475 = 68.6875\,(\text{m})$
④ 이동거리 — 배는 등대에서 멀어졌으므로 $\overline{DC} = 68.6875 - 17.505 = 51.1825\,(\text{m})$ → 반올림하여 51.2 m
채점 요소배점
엇각과 내각의 합으로 ∠HBD = 35°, ∠HBC = 70°를 구함1
HD = 25 tan 35° = 17.505 m1
HC = 25 tan 70° = 68.6875 m1
멀어졌으므로 DC = HC − HD 임을 밝힘1
반올림하여 51.2 m (단위 포함)1
⚡ 실전 체크리스트: ① 각이 연직선(등대)에서 잰 것인지, 수평선에서 잰 것인지 확인 ② 배가 다가오는지 멀어지는지 확인 ③ 표에서 tan를 고르고 곱셈이 되게 각을 정함 ④ 마지막에 한 번만 반올림하고 단위 m를 붙임
