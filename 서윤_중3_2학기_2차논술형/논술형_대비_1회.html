정답 및 풀이 · 채점 기준 (1회)

채점 기준은 학교 기준이 아니라 연습용 예시입니다. "왜 그렇게 되는지"를 한 줄씩 쓰는 습관이 만점의 핵심입니다.

1. 삼각비의 개념  1-1) AB : BC : CA = 12 : 5 : 13  /  1-2) $\sin A = \dfrac{5}{13}$, $\tan C = \dfrac{12}{5}$

① 빗변 찾기 — $\angle B = 90^\circ$ 이므로 빗변은 $\angle B$ 의 대변인 $\overline{AC}$ 이다.
② 두 변 정하기 — $\cos A = \dfrac{\overline{AB}}{\overline{AC}} = \dfrac{12}{13}$ 이므로 $\overline{AB} = 12k$, $\overline{AC} = 13k$ ($k > 0$) 로 놓는다.
③ 나머지 변 — 피타고라스 정리에 의해 $\overline{BC} = \sqrt{(13k)^2 - (12k)^2} = \sqrt{25k^2} = 5k$
④ 가장 간단한 자연수의 비 — $k = 1$ 로 하면 $\overline{AB} = 12$, $\overline{BC} = 5$, $\overline{CA} = 13$ (12, 5, 13의 최대공약수는 1)
답안 그림 예시 — ∠B에 직각 표시, 세 변 12, 5, 13
⑤ 1-2) — $\sin A = \dfrac{\overline{BC}}{\overline{AC}} = \dfrac{5}{13}$,   $\tan C = \dfrac{\overline{AB}}{\overline{BC}} = \dfrac{12}{5}$ ($\angle C$ 의 대변은 $\overline{AB}$, 이웃한 변은 $\overline{BC}$)
채점 요소배점
빗변이 AC임을 밝히고 $\cos A$ 로 AB : AC = 12 : 13을 세움1
피타고라스 정리로 BC = 5를 구하는 과정1
그림에 직각 표시(∠B)와 세 변 12, 5, 13을 모두 표시1
$\sin A = \dfrac{5}{13}$ / $\tan C = \dfrac{12}{5}$ (각 1점)2
⚡ 감점 함정: 교과서처럼 ∠C를 직각으로 그리면 그림부터 0점입니다. 시험지의 직각 위치를 먼저 확인하세요. $\tan C$ 는 "∠C에서 본 높이 ÷ 밑변"이므로 $\dfrac{5}{12}$ 로 뒤집어 쓰는 실수가 가장 흔합니다.

2. 특수각의 삼각비  $\dfrac{3}{4}$

① 각의 크기 — 삼각형의 세 내각의 합은 $180^\circ$ 이므로
$\angle A = 180^\circ \times \dfrac{1}{6} = 30^\circ$,   $\angle B = 180^\circ \times \dfrac{2}{6} = 60^\circ$,   $\angle C = 180^\circ \times \dfrac{3}{6} = 90^\circ$
② 값 대입 — $\sin 30^\circ = \dfrac{1}{2}$, $\cos 60^\circ = \dfrac{1}{2}$, $\tan 60^\circ = \sqrt{3}$, $\cos 30^\circ = \dfrac{\sqrt{3}}{2}$, $\sin 90^\circ = 1$
③ 계산 — $\dfrac{1}{2} \times \dfrac{1}{2} + \sqrt{3} \times \dfrac{\sqrt{3}}{2} - 1 = \dfrac{1}{4} + \dfrac{3}{2} - 1 = \dfrac{1}{4} + \dfrac{6}{4} - \dfrac{4}{4} = \dfrac{3}{4}$
채점 요소배점
내각의 합 180°를 근거로 세 각 30°, 60°, 90°를 구함2
다섯 개의 삼각비 값을 정확히 대입 (하나라도 틀리면 1점)2
계산 결과 $\dfrac{3}{4}$1
⚡ 감점 함정: 각을 구할 때 "세 내각의 합은 180°"라는 근거를 꼭 쓰세요. $\sin 90^\circ = 1$, $\cos 90^\circ = 0$ 도 특수값에 들어갑니다. ($\tan 90^\circ$ 는 정할 수 없습니다.)

3. 예각의 삼각비의 값  3-1) $\sin a = \dfrac{3}{5}$, $\tan a = \dfrac{3}{4}$  /  3-2) $\dfrac{48}{25}$  /  3-3) $\dfrac{3}{8}$

① 기준 삼각형 — 점 A에서 $x$축에 내린 수선의 발을 H라 하면, 직각삼각형 OHA에서 $\overline{OA} = 1$ (반지름)이므로
$\cos a = \dfrac{\overline{OH}}{\overline{OA}} = \overline{OH} = \dfrac{4}{5}$
② 3-1) — 피타고라스 정리로 $\overline{AH} = \sqrt{1^2 - \left(\dfrac{4}{5}\right)^2} = \sqrt{\dfrac{9}{25}} = \dfrac{3}{5}$
$\sin a = \dfrac{\overline{AH}}{\overline{OA}} = \dfrac{3}{5}$,   $\tan a = \dfrac{\overline{AH}}{\overline{OH}} = \dfrac{3}{5} \div \dfrac{4}{5} = \dfrac{3}{4}$
③ 3-2) — 직사각형의 각 변이 좌표축에 평행하므로 직사각형은 두 좌표축에 대하여 대칭이고, A$\left(\dfrac{4}{5}, \dfrac{3}{5}\right)$ 이고
가로 $\overline{AB} = 2 \times \dfrac{4}{5} = \dfrac{8}{5}$, 세로 $\overline{AD} = 2 \times \dfrac{3}{5} = \dfrac{6}{5}$ → 넓이 $= \dfrac{8}{5} \times \dfrac{6}{5} = \dfrac{48}{25}$
④ 3-3) — 직각삼각형 OET에서 $\overline{OE} = 1$ 이므로 $\tan a = \dfrac{\overline{ET}}{\overline{OE}} = \overline{ET} = \dfrac{3}{4}$
넓이 $= \dfrac{1}{2} \times \overline{OE} \times \overline{ET} = \dfrac{1}{2} \times 1 \times \dfrac{3}{4} = \dfrac{3}{8}$
채점 요소배점
3-1) 직각삼각형 OHA에서 OA = 1을 이용해 $\sin a$, $\tan a$ 를 구함 (각 1점)2
3-2) 가로 $\dfrac{8}{5}$, 세로 $\dfrac{6}{5}$ 을 근거와 함께 구하고 넓이 $\dfrac{48}{25}$2
3-3) $\overline{ET} = \tan a$ 임을 밝히고 넓이 $\dfrac{3}{8}$1
⚡ 핵심 원리: 반지름이 1이면 $\cos a$ = 점 A의 $x$좌표, $\sin a$ = 점 A의 $y$좌표, $\tan a$ = 접선 위 선분 ET의 길이입니다. 이 문장을 풀이 첫 줄에 쓰면 근거가 됩니다. 직사각형의 가로는 $x$좌표의 2배라는 점을 놓치지 마세요. 실전에서 (단) 조건이 없더라도 그림을 보고 "AB ∥ $x$축"이라는 근거를 한 줄 쓰세요.

4. 원과 현  4-2) $\overline{AB} = 16\,\text{cm}$

4-1) 모범 문장
원의 중심에서 현에 내린 수선은 그 현을 이등분한다. (따라서 $\overline{AM} = \overline{BM}$)
① 직각삼각형 — $\overline{OM} \perp \overline{AB}$ 이므로 △OAM은 $\angle OMA = 90^\circ$ 인 직각삼각형이다.
② 피타고라스 정리 — $\overline{AM} = \sqrt{\overline{OA}^2 - \overline{OM}^2} = \sqrt{10^2 - 6^2} = \sqrt{64} = 8\,(\text{cm})$
③ 현의 길이 — 4-1)의 성질에 의해 $\overline{AM} = \overline{BM}$ 이므로 $\overline{AB} = 2\overline{AM} = 2 \times 8 = 16\,(\text{cm})$
채점 요소배점
4-1) "중심에서 현에 내린 수선 → 현을 이등분" 문장 (주어·서술어 빠짐없이)2
4-2) 직각삼각형 OAM에서 피타고라스 정리로 AM = 8 cm2
4-2) 4-1)의 성질을 근거로 AB = 16 cm (단위 포함)1
⚡ 감점 함정: 4-1)은 "수직이등분한다"처럼 대충 쓰지 말고 무엇이(원의 중심에서 현에 내린 수선) 무엇을(그 현을) 어떻게(이등분)를 모두 넣으세요. 4-2)에서 AM = 8까지만 쓰고 멈추는 실수가 가장 흔합니다. 묻는 것은 현 AB 전체입니다.

5. 삼각비의 활용  약 $38.2\,\text{m}$

① 그림 해석 — 등대는 수면에 수직이므로 $\angle BAD = 90^\circ$ 이다. △ABD와 △ABC는 모두 점 A에서 직각인 직각삼각형이고, $\overline{AB} = 20\,\text{m}$ 는 두 삼각형에서 ∠B에 이웃한 변이다.
② 처음 위치까지의 거리 — △ABD에서 $\tan 70^\circ = \dfrac{\overline{AD}}{\overline{AB}}$ 이므로
$\overline{AD} = 20 \tan 70^\circ = 20 \times 2.7475 = 54.95\,(\text{m})$
③ 20초 후 위치까지의 거리 — △ABC에서 $\tan 40^\circ = \dfrac{\overline{AC}}{\overline{AB}}$ 이므로
$\overline{AC} = 20 \tan 40^\circ = 20 \times 0.8391 = 16.782\,(\text{m})$
④ 이동거리 — 배는 D에서 C로 등대 쪽으로 다가왔으므로
$\overline{CD} = \overline{AD} - \overline{AC} = 54.95 - 16.782 = 38.168\,(\text{m})$ → 소수 둘째 자리에서 반올림하면 38.2 m
(계산 줄이기: $\overline{CD} = 20(\tan 70^\circ - \tan 40^\circ) = 20 \times 1.9084 = 38.168$ 로 한 번에 계산해도 됩니다.)
채점 요소배점
∠A = 90°를 밝히고, 주어진 각에 대해 AB가 이웃한 변이므로 tan를 써야 함을 보임1
AD = 20 tan 70° = 54.95 m1
AC = 20 tan 40° = 16.782 m1
CD = AD − AC 로 이동거리를 세우는 근거1
반올림하여 38.2 m (단위 포함, "약" 또는 ≒)1
⚡ 감점 함정: 표에 sin, cos 값도 같이 주는 것은 고르는 능력을 보려는 것입니다. 꼭짓점 B에서 보면 AB는 이웃한 변, AD·AC는 마주 보는 변이므로 tan입니다. 계산 도중에는 반올림하지 말고 마지막에 한 번만 반올림하세요. 54.95를 54.9로 줄여 쓰면 54.9 − 16.782 = 38.118 ≒ 38.1이 되어 틀립니다.
