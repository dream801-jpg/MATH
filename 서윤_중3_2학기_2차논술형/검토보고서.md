## 2. P1 — 반드시 수정

### P1-1. [쓸데없는 조건 + 발문 모순] 3회 1번 `AC = 50 cm`
- 위치: `논술형_대비_3회.html` 145행
- 문제
  1. **쓸데없는 조건입니다.** 1-1은 "가장 간단한 자연수의 비"를, 1-2는 삼각비의 값을 묻습니다. 그래서 AC = 50 cm가 없어도 답이 똑같습니다.
  2. **발문과 모순됩니다.** 실제 길이가 14, 48, 50으로 정해지는데 1-1은 "각 변의 길이를 표시"하되 7, 24, 25로 쓰라고 합니다. 그러면 학생은 AC가 50인데 25라고 써야 하는 상황이 됩니다. 안내문의 고정 문장은 비만 주어지는 상황을 전제로 한 것으로 보입니다.
- 수정안(권장): 조건을 `$\sin C = \dfrac{14}{50}$`(약분하지 않은 분수)로 바꾸세요. 원래 의도한 "약분해서 7:24:25로 표시하기" 연습은 그대로 살고 모순은 없어집니다. 정답은 바뀌지 않습니다.
  - 같이 고칠 곳은 다음과 같습니다.
    - 풀이 ②·③(314~317행): "sin C = 14/50 = 7/25이므로 AB = 7k, AC = 25k"로 풀고, 피타고라스 정리로 BC = 24k를 구합니다.
    - 채점표 334·335행: "sin C를 약분해 AB : AC = 7 : 25를 세움" 1점, "피타고라스 정리로 BC = 24" 1점으로 바꿉니다.
    - 감점 함정(339행): "14, 48, 50을 그대로 쓰면 위반"은 "14 : 50을 약분하지 않고 쓰면 위반"으로 바꿉니다.
    - `README.md` 44행
- 대안: AC = 50 cm만 지우고 `sin C = 7/25`로 둡니다. 다만 그러면 약분 연습이 빠집니다.

### P1-2. [수학적 엄밀성] 3번(1~4회 공통) — "직사각형의 변이 좌표축에 평행하다"는 조건이 없음
- 위치
  - 각 회차 176행 (단) 문장
  - 풀이 근거
    - 1회 358행, 2회 360행: "직사각형은 두 좌표축에 대하여 대칭이므로"
    - 3회 362행: "y축에 대하여 대칭이므로"
    - 4회 358행: D의 좌표를 바로 씀
- 문제: 원에 내접하는 직사각형은 대각선이 지름이라는 것만 정해집니다. 꼭짓점 A가 정해져도 B의 위치는 자유롭기 때문에 **본문만으로는 3-2(직사각형 넓이)의 답이 하나로 정해지지 않습니다.** 3회는 더 심합니다. AB = 30/17에서 cos a = AB/2를 끌어내려면 "AB가 x축에 평행하다"는 조건이 꼭 있어야 합니다. 지금 풀이의 "대칭이므로"는 그림에서 눈으로 본 것이지 주어진 조건이 아닙니다. 논술형에서는 근거로 인정받지 못할 수 있습니다.
- 수정: 4개 파일의 176행 (단) 문장 앞에 "직사각형 ABCD의 각 변은 좌표축에 평행하고,"를 넣으세요.
  - 예: `(단, 직사각형 ABCD의 각 변은 좌표축에 평행하고, 점 E(1, 0)에서 원에 접하는 직선과 반직선 OA가 만나는 점을 T라 한다.)`
  - 풀이의 근거 문장도 "각 변이 좌표축에 평행하므로 직사각형은 두 좌표축에 대하여 대칭이고"로 바꾸세요.
  - 1회 핵심 원리 팁(368행)에 "실전에서는 그림을 보고 'AB ∥ x축'이라는 근거를 한 줄 쓴다"를 덧붙이면 좋습니다.

### P1-3. [그림 오류에 가까운 가독성] 2회 3번 그림 — A와 T가 거의 겹치고, 변 BT가 변 AB와 겹쳐 보임
- 위치: `논술형_대비_2회.html` 185~209행
- 문제: a ≈ 22.6°로 작아서 A(251.5, 107.7)와 T(260, 104.2)가 약 9px밖에 떨어져 있지 않습니다. 색칠한 △BET의 윗변 BT도 직사각형의 변 AB와 3px 정도로 붙어 있습니다. 출력물에서는 "B, A, T가 한 직선 위에 있다"거나 "T = A"처럼 보입니다. 3-3에서 T 대신 A를 쓰는 오답을 그림이 유도하는 셈입니다. 직사각형의 변 AD(x = 251.5)도 접선(x = 260)에 붙어 있어 라벨 D가 점선에 닿습니다.
- 수정(정답·조건은 그대로, 그림만 고침)
  - SVG를 키우세요(예: 반지름 110 → 150px, viewBox도 같이 키움). 그러면 A–T 간격과 BT–AB 간격이 늘어납니다.
  - A 라벨은 직사각형 안쪽 아래(A의 왼쪽 아래)로, T 라벨은 접선 오른쪽 위로 옮기세요. D 라벨은 점선과 떨어지도록 왼쪽으로 옮기세요.
  - 선분 BT와 BE는 색칠 경계 색(#b07a00)을 유지하되 굵기를 1.4로 올려 직사각형 변(남색)과 구별되게 하세요.
  - 렌더링한 뒤 "A와 T가 서로 다른 점으로 보이는지", "BT가 AB와 다른 선으로 보이는지"를 반드시 눈으로 확인하세요. 이것이 A4 한 쪽 안에 들어가지 않으면 답란 높이(212·214·216행)를 줄여 맞추세요.

## 5. 문제 없음으로 판단한 것 (수정봇이 건드리지 말 것)

- **5번 "20초"**: 1·2·4회에서는 쓰이지 않지만 안내문 고정 문장입니다(README 결정 사항). 유지하세요.
- **5번 표의 sin·cos 열, 3·4회 표의 추가 행(25°/50°, 20°/55°)**: 학생이 tan과 여각을 직접 고르게 하려고 일부러 넣은 것입니다. 쓸데없는 조건이 아닙니다.
- **2번 3·4회의 ∠C(105°, 75°)**: 비율에서 자동으로 생기는 각이고, 식에 쓰이지 않는다는 것을 풀이에서 밝히고 있습니다. 문제없습니다.
- **2번 1·2회의 sin 90°, cos 90°**: 중3 교과 범위(0°, 90°의 삼각비)에 들어갑니다.
- **2회 2번 1:1:2의 "작은 각부터 순서대로"**: ∠A = ∠B여서 순서가 모호해도 값에는 영향이 없습니다.
- **쪽 구성**: 4개 회차 모두 문제 1~5가 한 쪽씩 들어가고 잘린 곳이 없습니다(1·4회 8쪽, 2·3회 9쪽).
