정답 및 풀이 · 채점 기준 (3회)

채점 기준은 학교 기준이 아니라 연습용 예시입니다. "왜 그렇게 되는지"를 한 줄씩 쓰는 습관이 만점의 핵심입니다.

1. 삼각비의 개념  1-1) AB : BC : CA = 7 : 24 : 25  /  1-2) $\cos A = \dfrac{7}{25}$, $\tan A = \dfrac{24}{7}$

① 변의 위치 — $\angle B = 90^\circ$ 이므로 빗변은 $\overline{AC}$ 이고, $\angle C$ 의 대변은 $\overline{AB}$ 이다.
② 두 변 정하기 — $\sin C = \dfrac{\overline{AB}}{\overline{AC}} = \dfrac{7}{25}$ 이므로 $\overline{AB} = 7k$, $\overline{AC} = 25k$ ($k > 0$) 로 놓는다.
③ 나머지 변 — 피타고라스 정리에 의해 $\overline{BC} = \sqrt{(25k)^2 - (7k)^2} = \sqrt{576k^2} = 24k$
$k = 1$ 로 하면 $\overline{AB} : \overline{BC} : \overline{CA} = 7 : 24 : 25$ (7, 24, 25의 최대공약수는 1)
답안 그림 예시 — ∠B에 직각 표시, 세 변 7, 24, 25
④ 1-2) — $\cos A = \dfrac{\overline{AB}}{\overline{AC}} = \dfrac{7}{25}$,   $\tan A = \dfrac{\overline{BC}}{\overline{AB}} = \dfrac{24}{7}$
채점 요소배점
∠C의 대변이 AB임을 밝히고 $\sin C$ 로 AB : AC = 7 : 25를 세움1
피타고라스 정리로 BC = 24를 구하는 과정1
그림에 직각 표시(∠B)와 가장 간단한 비 7, 24, 25를 표시1
$\cos A = \dfrac{7}{25}$ / $\tan A = \dfrac{24}{7}$ (각 1점)2
⚡ 감점 함정: $\sqrt{625 - 49} = \sqrt{576} = 24$ 처럼 수가 크면 $24^2 = 576$ 을 떠올리세요. 7 : 24 : 25는 3 : 4 : 5, 5 : 12 : 13, 8 : 15 : 17과 함께 자주 나오는 비입니다. ∠C 기준이므로 대변은 BC가 아니라 AB입니다. 직각삼각형에서 $\sin C = \cos A$ 입니다(검산용).

2. 특수각의 삼각비  $\dfrac{3}{2}$

① 각의 크기 — 삼각형의 세 내각의 합은 $180^\circ$ 이므로 (비의 합 $2+3+7 = 12$)
$\angle A = 180^\circ \times \dfrac{2}{12} = 30^\circ$,   $\angle B = 180^\circ \times \dfrac{3}{12} = 45^\circ$,   $\angle C = 180^\circ \times \dfrac{7}{12} = 105^\circ$
② 확인 — $\angle C = 105^\circ$ 는 특수각이 아니지만 식에 $\angle C$ 가 없으므로 계산할 수 있다.
③ 값 대입 — $\cos 45^\circ = \dfrac{\sqrt{2}}{2}$, $\sin 30^\circ = \dfrac{1}{2}$, $\tan 30^\circ = \dfrac{\sqrt{3}}{3}$
④ 계산 — $\sqrt{2} \times \dfrac{\sqrt{2}}{2} \times \dfrac{1}{2} + \sqrt{3} \times \dfrac{\sqrt{3}}{3} = \dfrac{2}{2} \times \dfrac{1}{2} + \dfrac{3}{3} = \dfrac{1}{2} + 1 = \dfrac{3}{2}$
채점 요소배점
내각의 합 180°를 근거로 세 각 30°, 45°, 105°를 구함2
세 삼각비 값을 정확히 대입 (하나라도 틀리면 1점)2
계산 결과 $\dfrac{3}{2}$1
⚡ 감점 함정: 비가 2 : 3 : 7이면 비의 합이 12입니다. 6이나 10으로 나누는 실수에 주의하세요. $\tan 30^\circ = \dfrac{1}{\sqrt{3}} = \dfrac{\sqrt{3}}{3}$ 은 두 형태 모두 알아 두세요.

3. 예각의 삼각비의 값  3-1) $\sin a = \dfrac{8}{17}$, $\tan a = \dfrac{8}{15}$  /  3-2) $\dfrac{480}{289}$  /  3-3) $\dfrac{128}{255}$

① 점 A의 $x$좌표 — 직사각형의 각 변이 좌표축에 평행하므로 직사각형은 $y$축에 대하여 대칭이고, 점 A의 $x$좌표는 $\dfrac{1}{2}\overline{AB} = \dfrac{15}{17}$ 이다.
점 A에서 $x$축에 내린 수선의 발을 H라 하면 $\overline{OH} = \dfrac{15}{17}$, $\overline{OA} = 1$ 이므로 $\cos a = \dfrac{15}{17}$
② 3-1) — $\overline{AH} = \sqrt{1^2 - \left(\dfrac{15}{17}\right)^2} = \sqrt{\dfrac{64}{289}} = \dfrac{8}{17}$
$\sin a = \dfrac{\overline{AH}}{\overline{OA}} = \dfrac{8}{17}$,   $\tan a = \dfrac{\overline{AH}}{\overline{OH}} = \dfrac{8}{17} \div \dfrac{15}{17} = \dfrac{8}{15}$
③ 3-2) — 세로 $\overline{AD} = 2 \times \dfrac{8}{17} = \dfrac{16}{17}$ 이므로 넓이 $= \dfrac{30}{17} \times \dfrac{16}{17} = \dfrac{480}{289}$
④ 3-3) — 사각형 ODET를 선분 OE로 나누면 △OET와 △ODE가 된다.
△OET: $\overline{ET} = \tan a = \dfrac{8}{15}$ 이므로 넓이 $= \dfrac{1}{2} \times 1 \times \dfrac{8}{15} = \dfrac{4}{15}$
△ODE: 밑변 $\overline{OE} = 1$, 높이는 점 D의 $y$좌표의 절댓값 $\dfrac{8}{17}$ 이므로 넓이 $= \dfrac{1}{2} \times 1 \times \dfrac{8}{17} = \dfrac{4}{17}$
합: $\dfrac{4}{15} + \dfrac{4}{17} = \dfrac{68 + 60}{255} = \dfrac{128}{255}$
채점 요소배점
3-1) $\overline{AB}$ 의 절반이 $\cos a$ 임을 밝히고 $\sin a$, $\tan a$ (각 1점)2
3-2) 세로 $\dfrac{16}{17}$ 을 구하고 넓이 $\dfrac{480}{289}$2
3-3) 두 삼각형으로 나누어 넓이 $\dfrac{128}{255}$1
⚡ 핵심: 조건이 각이 아니라 변의 길이로 주어졌습니다. "가로의 절반 = A의 $x$좌표 = $\cos a$"로 연결하는 문장을 꼭 쓰세요. 사각형 넓이는 좌표축 위의 선분 OE를 공통 밑변으로 잘라서 구하는 것이 가장 안전합니다.

4. 원과 현  4-2) $36\,\text{cm}$

4-1) 모범 문장
한 원에서 중심으로부터 같은 거리에 있는 두 현의 길이는 서로 같다. (따라서 $\overline{AB} = \overline{CD}$)
① 현 AB의 길이 — $\overline{OM} = \overline{ON}$ 이므로 4-1)에 의해 $\overline{AB} = \overline{CD} = 16\,\text{cm}$
② 반지름 — 원의 중심에서 현에 내린 수선은 그 현을 이등분하므로 $\overline{AM} = 8\,\text{cm}$
직각삼각형 OAM에서 $\overline{OA} = \sqrt{8^2 + 6^2} = \sqrt{100} = 10\,(\text{cm})$, 같은 원의 반지름이므로 $\overline{OB} = 10\,\text{cm}$
③ 둘레 — $\overline{OA} + \overline{OB} + \overline{AB} = 10 + 10 + 16 = 36\,(\text{cm})$
채점 요소배점
4-1) "중심으로부터 같은 거리에 있는 두 현의 길이는 같다" 문장2
4-2) AB = 16, AM = 8 (이등분 성질 근거 포함)1
4-2) 피타고라스 정리로 OA = OB = 101
4-2) 둘레 36 cm (단위 포함)1
⚡ 감점 함정: 성질을 두 개(같은 거리 → 같은 길이, 수선 → 이등분) 이어서 써야 하는 문제입니다. 두 번째 성질도 근거로 한 줄 적어야 감점이 없습니다.

5. 삼각비의 활용  이동거리 약 $52.2\,\text{m}$, 속력 약 초속 $2.6\,\text{m}$

① 각 옮기기 — 이번 각은 수평선 BA에서 잰 각(내려본각)이다. $\overline{BA} \parallel \overline{HD}$ 이므로 엇각으로 $\angle BDH = 25^\circ$, $\angle BCH = 50^\circ$ 이다.
△BHD에서 $\angle HBD = 90^\circ - 25^\circ = 65^\circ$, △BHC에서 $\angle HBC = 90^\circ - 50^\circ = 40^\circ$
② 처음 위치 — 직각삼각형 BHD에서 $\overline{HD} = 40 \tan 65^\circ = 40 \times 2.1445 = 85.78\,(\text{m})$
③ 20초 후 위치 — 직각삼각형 BHC에서 $\overline{HC} = 40 \tan 40^\circ = 40 \times 0.8391 = 33.564\,(\text{m})$
④ 이동거리 — 배는 등대 쪽으로 다가왔으므로 $\overline{CD} = 85.78 - 33.564 = 52.216\,(\text{m})$ → 반올림하여 52.2 m
⑤ 속력 — $52.216 \div 20 = 2.6108$ → 반올림하여 초속 2.6 m
채점 요소배점
엇각과 내각의 합으로 ∠HBD = 65°, ∠HBC = 40°를 구함1
HD = 40 tan 65° = 85.78, HC = 40 tan 40° = 33.5641
CD = HD − HC 로 이동거리 52.2 m2
속력 초속 2.6 m (반올림 전 값 52.216으로 계산)1
⚡ 감점 함정: $\overline{HD} = \dfrac{40}{\tan 25^\circ}$ 로 세워도 맞지만 계산기 없이 $40 \div 0.4663$ 은 어렵습니다. 여각(65°)으로 바꿔 곱셈으로 만드는 것이 이 문제의 핵심입니다. 표에 25°와 65°가 같이 있는 이유입니다. 속력은 반올림한 52.2가 아니라 52.216으로 나누세요.
