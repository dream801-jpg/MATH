문제 1. 점, 선, 면 (20점)
다음 그림과 같이 직선 $l$ 위에 네 점 $\text{A, B, C, D}$ 가 있고, 직선 $l$ 위에 있지 않은 한 점 $\text{P}$ 가 있다.
(1) 다섯 개의 점 $\text{A, B, C, D, P}$ 중 두 점을 이어 만들 수 있는 서로 다른 직선, 반직선, 선분의 개수를 각각 구하시오. (단, 개수를 센 방법을 서술할 것) (12점)
(2) (1)의 그림과 관계없이, 선분 $\text{AB}$ 위의 점 $\text{M}$ 은 $\overline{\text{AB}}$ 의 중점이고, 점 $\text{N}$ 은 $\overline{\text{MB}}$ 의 중점이다. $\overline{\text{AN}} = 18\,\text{cm}$ 일 때, $\overline{\text{AB}}$ 와 $\overline{\text{MN}}$ 의 길이를 각각 구하시오. (풀이 과정 서술) (8점)
문제 2. 위치관계 (20점)
다음 그림은 옆면이 모두 직사각형인 삼각기둥 $\text{ABC-DEF}$ 이다.
(1) 모서리 $\text{AB}$ 와 꼬인 위치에 있는 모서리를 모두 구하시오. (5점)
(2) 모서리 $\text{AD}$ 와 평행한 면의 개수를 $a$, 면 $\text{ABC}$ 와 수직인 모서리의 개수를 $b$, 모서리 $\text{BC}$ 와 꼬인 위치에 있는 모서리의 개수를 $c$ 라 할 때, $a+b+c$ 의 값을 구하시오. (7점)
(3) 다음은 공간에서 직선과 평면의 위치관계에 대한 설명이다. 옳지 않은 것을 모두 고르고, 옳지 않은 이유를 위 삼각기둥의 모서리나 면을 예로 들어 설명하시오. (8점)
ㄱ. 한 평면에 평행한 서로 다른 두 직선은 평행하다.
ㄴ. 한 평면에 수직인 서로 다른 두 직선은 평행하다.
ㄷ. 한 직선에 수직인 서로 다른 두 직선은 평행하다.
ㄹ. 한 직선에 수직인 서로 다른 두 평면은 평행하다.
문제 3. 삼각형의 작도 (20점)
(1) 길이가 각각 $2\,\text{cm},\ 3\,\text{cm},\ 5\,\text{cm},\ 6\,\text{cm},\ 8\,\text{cm}$ 인 막대가 하나씩 있다. 이 중 세 개를 골라 만들 수 있는 서로 다른 삼각형의 개수를 구하시오. (단, 삼각형이 되는 조건을 이용하여 판단 과정을 서술할 것) (8점)
(2) 다음 중 $\triangle\text{ABC}$ 가 하나로 정해지는 것을 모두 고르시오. 또, 하나로 정해지지 않는 것은 각각 그 이유를 쓰시오. (12점)
ㄱ. $\overline{\text{AB}} = 4\,\text{cm},\ \overline{\text{BC}} = 6\,\text{cm},\ \overline{\text{CA}} = 10\,\text{cm}$
ㄴ. $\overline{\text{AB}} = 5\,\text{cm},\ \overline{\text{BC}} = 7\,\text{cm},\ \angle\text{B} = 40^\circ$
ㄷ. $\overline{\text{AB}} = 6\,\text{cm},\ \overline{\text{CA}} = 5\,\text{cm},\ \angle\text{B} = 50^\circ$
ㄹ. $\overline{\text{BC}} = 8\,\text{cm},\ \angle\text{B} = 70^\circ,\ \angle\text{C} = 110^\circ$
ㅁ. $\overline{\text{AC}} = 7\,\text{cm},\ \angle\text{A} = 50^\circ,\ \angle\text{B} = 60^\circ$
ㅂ. $\angle\text{A} = 40^\circ,\ \angle\text{B} = 60^\circ,\ \angle\text{C} = 80^\circ$
문제 4. 평행선의 성질 (20점)
(1) [그림 1]에서 $l \,/\!/\, m$ 일 때, $\angle x$ 의 크기를 구하시오. (단, 보조선을 어떻게 그었는지와 이용한 성질을 서술할 것) (8점)
(2) [그림 2]는 폭이 일정한 직사각형 모양의 종이 테이프를 선분 $\text{AB}$ 를 접는 선으로 하여 접은 것이고, 점 $\text{D}$ 는 접기 전 테이프의 윗변 위의 점이다. $\angle\text{ABC} = 65^\circ$ 일 때, $\angle x$ 의 크기를 구하시오. (단, 이용한 성질을 서술할 것) (12점)
문제 5. 삼각형의 합동 (20점)
다음 그림에서 $\triangle\text{ABC}$ 와 $\triangle\text{ADE}$ 는 모두 정삼각형이고, 점 $\text{D}$ 는 $\overline{\text{BC}}$ 위의 점이다.
(1) $\triangle\text{ABD} \equiv \triangle\text{ACE}$ 임을 설명하시오. (단, 대응하는 변과 각이 같은 이유와 합동 조건을 밝힐 것) (10점)
(2) $\overline{\text{BC}} = 10\,\text{cm},\ \overline{\text{CD}} = 3\,\text{cm}$ 일 때, $\overline{\text{CE}}$ 의 길이를 구하시오. (4점)
(3) $\angle\text{DCE}$ 의 크기를 구하시오. (풀이 과정 서술) (6점)

문제 1 풀이

(1)
구분직선 $l$ 위의 네 점끼리점 $\text{P}$ 와 네 점합계
직선모두 직선 $l$ 로 같음 → $1$ 개$\overleftrightarrow{\text{PA}}, \overleftrightarrow{\text{PB}}, \overleftrightarrow{\text{PC}}, \overleftrightarrow{\text{PD}}$ → $4$ 개$5$
반직선$\overrightarrow{\text{AB}}\,(=\overrightarrow{\text{AC}}=\overrightarrow{\text{AD}}),\ \overrightarrow{\text{BA}},\ \overrightarrow{\text{BC}},\ \overrightarrow{\text{CB}},\ \overrightarrow{\text{CD}},\ \overrightarrow{\text{DC}}$ → $6$ 개$\overrightarrow{\text{PA}}, \overrightarrow{\text{AP}}$ 처럼 점마다 $2$ 개 → $8$ 개$14$
선분$\overline{\text{AB}}, \overline{\text{AC}}, \overline{\text{AD}}, \overline{\text{BC}}, \overline{\text{BD}}, \overline{\text{CD}}$ → $6$ 개$\overline{\text{PA}}, \overline{\text{PB}}, \overline{\text{PC}}, \overline{\text{PD}}$ → $4$ 개$10$
직선 $5$ 개, 반직선 $14$ 개, 선분 $10$ 개
(2) $\overline{\text{AM}} = \overline{\text{MB}} = \dfrac{1}{2}\overline{\text{AB}}$, $\overline{\text{MN}} = \dfrac{1}{2}\overline{\text{MB}} = \dfrac{1}{4}\overline{\text{AB}}$ 이므로
$\overline{\text{AN}} = \overline{\text{AM}} + \overline{\text{MN}} = \dfrac{1}{2}\overline{\text{AB}} + \dfrac{1}{4}\overline{\text{AB}} = \dfrac{3}{4}\overline{\text{AB}} = 18$
$\overline{\text{AB}} = 18 \times \dfrac{4}{3} = 24$,   $\overline{\text{MN}} = \dfrac{1}{4} \times 24 = 6$
$\overline{\text{AB}} = 24\,\text{cm}$, $\overline{\text{MN}} = 6\,\text{cm}$
⚡ 채점 포인트:
  • 한 직선 위의 점끼리는 직선은 1개뿐이고, 반직선은 $\overrightarrow{\text{AB}} = \overrightarrow{\text{AC}}$ 처럼 시작점과 방향이 같으면 같은 반직선. 이걸 빼먹고 $20$ 개로 세면 감점.
  • 반직선은 $\overrightarrow{\text{PA}} \ne \overrightarrow{\text{AP}}$ (시작점이 다름), 선분·직선은 $\overline{\text{PA}} = \overline{\text{AP}}$.

문제 2 풀이

(1) 모서리 $\text{AB}$ 와 만나는 모서리: $\text{AC, AD, BC, BE}$ / 평행한 모서리: $\text{DE}$
나머지가 꼬인 위치 → $\overline{\text{CF}},\ \overline{\text{DF}},\ \overline{\text{EF}}$
(2)
  • $a$: 모서리 $\text{AD}$ 와 평행한 면 → 면 $\text{BEFC}$ 뿐 → $a = 1$ (면 $\text{ABED}$, $\text{ADFC}$ 는 $\text{AD}$ 를 포함, 면 $\text{ABC}$, $\text{DEF}$ 는 수직)
  • $b$: 면 $\text{ABC}$ 와 수직인 모서리 → $\text{AD, BE, CF}$ → $b = 3$
  • $c$: 모서리 $\text{BC}$ 와 꼬인 위치 → $\text{AD, DE, DF}$ → $c = 3$
$a + b + c = 1 + 3 + 3 = $ $7$
(3) 옳지 않은 것: ㄱ, ㄷ
  • ㄱ — 모서리 $\text{AB}$ 와 $\text{BC}$ 는 모두 면 $\text{DEF}$ 와 평행하지만, 점 $\text{B}$ 에서 만난다. (주의: $\text{EF}$ 는 면 $\text{DEF}$ 에 포함된 모서리라 "평행한 직선"의 예가 될 수 없음)
  • ㄷ — 모서리 $\text{AB}$ 와 $\text{AC}$ 는 모두 모서리 $\text{AD}$ 와 수직이지만, 점 $\text{A}$ 에서 만난다. 또 $\text{AB}$ 와 $\text{EF}$ 는 모두 $\text{BE}$ 와 수직이지만 꼬인 위치이다.
  • ㄴ(예: $\text{AD} /\!/ \text{BE}$, 둘 다 면 $\text{ABC}$ 에 수직), ㄹ(예: 면 $\text{ABC} /\!/$ 면 $\text{DEF}$, 둘 다 $\text{AD}$ 에 수직)은 옳다.
⚡ 채점 포인트: (3)은 "옳지 않다"만 쓰면 부분점수. 구체적인 모서리 이름으로 반례를 들어야 만점. 평면에서는 ㄷ이 참이지만 공간에서는 거짓이라는 점이 핵심.

문제 3 풀이

(1) 삼각형이 되는 조건: (가장 긴 변의 길이) < (나머지 두 변의 길이의 합)
세 막대판정세 막대판정
$2, 3, 5$$5 = 2+3$ ✗$2, 6, 8$$8 = 2+6$ ✗
$2, 3, 6$$6 > 5$ ✗$3, 5, 6$$6 < 8$ ○
$2, 3, 8$$8 > 5$ ✗$3, 5, 8$$8 = 3+5$ ✗
$2, 5, 6$$6 < 7$ ○$3, 6, 8$$8 < 9$ ○
$2, 5, 8$$8 > 7$ ✗$5, 6, 8$$8 < 11$ ○
$4$ 개 — $(2,5,6),\ (3,5,6),\ (3,6,8),\ (5,6,8)$
(2) 하나로 정해지는 것: ㄴ, ㅁ
  • ㄴ: 두 변과 그 끼인각($\angle\text{B}$ 는 $\overline{\text{AB}}, \overline{\text{BC}}$ 사이의 각) → 하나로 정해짐
  • ㅁ: $\angle\text{C} = 180^\circ - 50^\circ - 60^\circ = 70^\circ$ 이므로 한 변 $\overline{\text{AC}}$ 와 그 양 끝각 $\angle\text{A}, \angle\text{C}$ 를 아는 것과 같다 → 하나로 정해짐
  • ㄱ: $10 = 4 + 6$ → 가장 긴 변이 나머지 두 변의 합보다 작지 않으므로 삼각형이 만들어지지 않는다
  • ㄷ: $\angle\text{B}$ 는 $\overline{\text{AB}}, \overline{\text{CA}}$ 의 끼인각이 아니다 → 삼각형이 하나로 정해지지 않는다 (실제로 $2$ 개 그려짐)
  • ㄹ: $\angle\text{B} + \angle\text{C} = 180^\circ$ → 두 각의 합이 $180^\circ$ 보다 작지 않으므로 삼각형이 만들어지지 않는다
  • ㅂ: 세 각의 크기만 주어짐 → 모양은 같고 크기가 다른 삼각형이 무수히 많다
⚡ 채점 포인트:
  • (1) $2+3=5$, $2+6=8$, $3+5=8$ 처럼 합이 같은 경우를 삼각형으로 세면 오답 (등호는 안 됨).
  • (2) ㅁ은 "끼인변이 아니라서 안 된다"로 틀리기 쉬움 → 나머지 한 각을 구하면 ASA가 됨을 써야 함. ㄷ은 반대로 "두 변과 한 각이니 된다"로 틀리기 쉬움.

문제 4 풀이

(1) 꺾인 두 꼭짓점($\angle x$ 인 점, $65^\circ$ 인 점)을 각각 지나고 $l$ 에 평행한 직선 $p, q$ 를 긋는다. ($l /\!/ p /\!/ q /\!/ m$)
  • $65^\circ$ 인 꼭짓점에서: $65^\circ$ 를 $q$ 가 둘로 나눔. 아래쪽 각 $= 25^\circ$ ($m$ 과의 엇각) → 위쪽 각 $= 65^\circ - 25^\circ = 40^\circ$
  • $\angle x$ 인 꼭짓점에서: $\angle x$ 를 $p$ 가 둘로 나눔. 위쪽 각 $= 30^\circ$ ($l$ 과의 엇각), 아래쪽 각 $= 40^\circ$ ($q$ 와의 엇각)
$\angle x = 30^\circ + 40^\circ = $ $70^\circ$
검산: (오른쪽으로 뾰족한 각의 합) $= x + 25^\circ$ , (왼쪽으로 뾰족한 각의 합) $= 30^\circ + 65^\circ$ → $x = 70^\circ$ ✓
(2)
  • 테이프의 위아래 변은 평행하므로 $\angle\text{DAB} = \angle\text{ABC} = 65^\circ$ (엇각)
  • 접은 각은 같으므로 $\angle\text{BAC} = \angle\text{DAB} = 65^\circ$ (접은 각)
  • $\triangle\text{ABC}$ 에서 $\angle x = 180^\circ - (65^\circ + 65^\circ) = $ $50^\circ$
⚡ 채점 포인트: (1) 꺾인 꼭짓점마다 평행한 보조선을 긋고 엇각으로 옮기는 과정이 서술되어야 함. 다른 정당한 방법도 인정. (2) "엇각"과 "접은 각"이라는 근거 두 가지를 모두 써야 만점.

문제 5 풀이

(1) $\triangle\text{ABD}$ 와 $\triangle\text{ACE}$ 에서
  • $\overline{\text{AB}} = \overline{\text{AC}}$ ($\triangle\text{ABC}$ 는 정삼각형) ····· ①
  • $\overline{\text{AD}} = \overline{\text{AE}}$ ($\triangle\text{ADE}$ 는 정삼각형) ····· ②
  • $\angle\text{BAD} = 60^\circ - \angle\text{DAC} = \angle\text{CAE}$ ($\angle\text{BAC} = \angle\text{DAE} = 60^\circ$) ····· ③
①, ②, ③에 의해 $\triangle\text{ABD} \equiv \triangle\text{ACE}$ ($\text{SAS}$ 합동)
(2) $\overline{\text{BD}} = \overline{\text{BC}} - \overline{\text{CD}} = 10 - 3 = 7$ 이고, 합동인 도형의 대응변이므로 $\overline{\text{CE}} = \overline{\text{BD}} = $ $7\,\text{cm}$
(3) 대응각이므로 $\angle\text{ACE} = \angle\text{ABD} = 60^\circ$
$\angle\text{DCE} = \angle\text{ACD} + \angle\text{ACE} = 60^\circ + 60^\circ = $ $120^\circ$
⚡ 채점 포인트:
  • ③의 끼인각을 "정삼각형이라 $60^\circ$"로 쓰면 오답 — $\angle\text{BAD}$ 는 $60^\circ$ 가 아님. 공통인 $\angle\text{DAC}$ 를 빼서 같음을 보여야 함.
  • 합동 기호는 대응 순서대로 ($\text{A}\to\text{A},\ \text{B}\to\text{C},\ \text{D}\to\text{E}$).
