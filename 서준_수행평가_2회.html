문제 1 풀이

(1) $A = 3a, B = 3b, C = 3c$ 이므로 양변을 $3$ 으로 나누면:
  • $a < b < c$ (자연수)
  • $a, b, c$ 의 최대공약수 $= 1$
  • $a, b, c$ 의 최소공배수 $= 30 \;(= 90 \div 3)$
  • $a + b + c = 14 \;(= 42 \div 3)$
(2) $30$ 의 약수 $\{1, 2, 3, 5, 6, 10, 15, 30\}$ 중 세 개를 골라 위 조건을 모두 만족:
$(a, b, c)$합최대공약수최소공배수판정
$(1, 3, 10)$$14$$1$$30$✓
$(3, 5, 6)$$14$$1$$30$✓
따라서 $(A, B, C) = (3, 9, 30)$ 또는 $(9, 15, 18)$
(3)
  • $3 \times 9 \times 30 = 27 \times 30 = 810$
  • $9 \times 15 \times 18 = 135 \times 18 = 2{,}430$
차 $= 2{,}430 - 810 = $ $1{,}620$
⚡ 채점 포인트: GCD로 나눠 단순화하는 아이디어 명시 + 답 2쌍 모두 제시.

문제 2 풀이

(1) $\mathrm{C} \times \mathrm{A} \times \mathrm{K} \times \mathrm{E} = 5 \times 2 \times 31 \times 11$
  • $5 \times 2 = 10$
  • $31 \times 11 = 341$
  • $10 \times 341 = $ $3{,}410$
(2) $6{,}710$ 을 작은 소수부터 순차 나누기:
나눈 소수몫
$\div 2$$3{,}355$
$\div 5$$671$
$\div 11$$61$ (소수)
$6{,}710 = 2 \times 5 \times 11 \times 61$
소인수에 대응하는 알파벳: {A, C, E, R}
가능한 단어 예: CARE (또는 RACE, ACRE 모두 가능)
(3) 두 자연수가 서로소 ⟺ 공통된 소인수가 없음. 두 암호가 서로소이면 두 암호의 소인수 집합에 공통 원소가 없으므로, 그에 대응하는 알파벳에도 공통 원소가 없다. 즉 두 단어는 공통된 알파벳을 하나도 가지지 않는다.
⚡ 채점 포인트: (3)에서 "서로소 $\Rightarrow$ 공통 소인수 없음 $\Rightarrow$ 공통 알파벳 없음" 논리 사슬 명시.

문제 3 풀이

(1) 4행 직접 합산 (분모 4로 통분):
$-1 + \dfrac{7}{4} + \dfrac{3}{2} + \left(-\dfrac{7}{4}\right) = -\dfrac{4}{4} + \dfrac{7}{4} + \dfrac{6}{4} - \dfrac{7}{4} = \dfrac{-4 + 7 + 6 - 7}{4} = \dfrac{2}{4}$ $\Rightarrow$ $S = \dfrac{1}{2}$
(2) 각 줄의 합 $= \dfrac{1}{2}$. 미지수가 1개만 남은 줄부터 차례로:
순서사용 줄식결과

②3열$-\frac{3}{2} + ? + (-\frac{1}{4}) + \frac{3}{2} = \frac{1}{2}$(2,3) $= \frac{3}{4}$
③2행$-\frac{3}{4} + \frac{1}{2} + \frac{3}{4} + ? = \frac{1}{2}$(2,4) $= 0$
④4열$? + 0 + 1 + (-\frac{7}{4}) = \frac{1}{2}$(1,4) $= \frac{5}{4}$
⑤1행$? + (-\frac{5}{4}) + (-\frac{3}{2}) + \frac{5}{4} = \frac{1}{2}$(1,1) $= 2$
⑥3행$? + (-\frac{1}{2}) + (-\frac{1}{4}) + 1 = \frac{1}{2}$(3,1) $= \frac{1}{4}$
⑦1열 검산$2 + (-\frac{3}{4}) + \frac{1}{4} + (-1) = \frac{1}{2}$ ✓—
⑧대각선 ↘ 검산$2 + \frac{1}{2} + (-\frac{1}{4}) + (-\frac{7}{4}) = \frac{1}{2}$ ✓—

문제 4 풀이

(1) 각 수의 값:
  • A $= \left(-\dfrac{3}{4}\right)^2 \div \left(-\dfrac{9}{8}\right) \times (-2)^3$
    $= \dfrac{9}{16} \div \left(-\dfrac{9}{8}\right) \times (-8)$ $= \dfrac{9}{16} \times \left(-\dfrac{8}{9}\right) \times (-8)$ $= \left(-\dfrac{1}{2}\right) \times (-8) = $ $4$
  • B $= -\left(\dfrac{1}{3}\right)^2 \times \left(-\dfrac{6}{5}\right)^2 \div \left(-\dfrac{2}{5}\right)$
    $= -\dfrac{1}{9} \times \dfrac{36}{25} \div \left(-\dfrac{2}{5}\right)$ $= -\dfrac{4}{25} \div \left(-\dfrac{2}{5}\right)$ $= -\dfrac{4}{25} \times \left(-\dfrac{5}{2}\right) = $ $\dfrac{2}{5}$
  • C $= \left|-\dfrac{5}{12} \div \dfrac{5}{6} \times (-2)\right| \times (-1)^9$
    안 계산: $-\dfrac{5}{12} \times \dfrac{6}{5} = -\dfrac{1}{2}$; $\;-\dfrac{1}{2} \times (-2) = 1$
    $\Rightarrow C = |1| \times (-1) = $ $-1$
  • D $= (-1)^3 \times \left(-\dfrac{2}{3}\right)^2 \div \left(-\dfrac{4}{9}\right)^2$
    $= -1 \times \dfrac{4}{9} \div \dfrac{16}{81}$ $= -\dfrac{4}{9} \times \dfrac{81}{16}$ $= -\dfrac{324}{144} = $ $-\dfrac{9}{4}$
  • E $= \left(-\dfrac{5}{4}\right)^2 \div \left(-\dfrac{25}{8}\right) \times \dfrac{2}{3}$
    $= \dfrac{25}{16} \div \left(-\dfrac{25}{8}\right) \times \dfrac{2}{3}$ $= \dfrac{25}{16} \times \left(-\dfrac{8}{25}\right) \times \dfrac{2}{3}$ $= -\dfrac{1}{2} \times \dfrac{2}{3} = $ $-\dfrac{1}{3}$
(2) 정리: $A = 4, \;B = \dfrac{2}{5}, \;C = -1, \;D = -\dfrac{9}{4}, \;E = -\dfrac{1}{3}$
(소수로 비교: $-\dfrac{9}{4} = -2.25, \;-1, \;-\dfrac{1}{3} \approx -0.33, \;\dfrac{2}{5} = 0.4, \;4$)
$D \;<\; C \;<\; E \;<\; B \;<\; A$   즉  $-\dfrac{9}{4} \;<\; -1 \;<\; -\dfrac{1}{3} \;<\; \dfrac{2}{5} \;<\; 4$
(3) 절댓값: $|A| = 4, \;|B| = \dfrac{2}{5}, \;|C| = 1, \;|D| = \dfrac{9}{4}, \;|E| = \dfrac{1}{3}$
합 $= 4 + \dfrac{2}{5} + 1 + \dfrac{9}{4} + \dfrac{1}{3} = 5 + \dfrac{2}{5} + \dfrac{9}{4} + \dfrac{1}{3}$
공통분모 $60$ 으로 통분: $= \dfrac{300}{60} + \dfrac{24}{60} + \dfrac{135}{60} + \dfrac{20}{60} = \dfrac{479}{60}$
$\Rightarrow$ $\dfrac{479}{60}$  (기약분수: $479$ 와 $60$ 의 최대공약수 $= 1$)
⚡ 채점 포인트:
  • A: $\left(-\frac{3}{4}\right)^2$ 양수, $(-2)^3 = -8$ 음수 — 부호 두 번 뒤집힘
  • B: $-\left(\frac{1}{3}\right)^2$ 의 음수 부호가 제곱 밖에 있음에 주의
  • C: 절댓값 안 먼저 계산 → $|1|$ 로 정리 → $(-1)^9 = -1$ 처리
  • D: $(-1)^3 = -1$, 그리고 $\left(-\frac{4}{9}\right)^2$ 분모도 제곱 — 약분 정확하게
  • E: 분수 약분으로 $\dfrac{25}{16} \times \dfrac{8}{25} = \dfrac{1}{2}$ 빠르게
