문제 1. 최대공약수와 최소공배수 (25점)
세 자연수 $A, B, C$ 가 다음 조건을 모두 만족한다.
  • $A < B < C$
  • $A, B, C$ 의 최대공약수는 4
  • $A, B, C$ 의 최소공배수는 120

(1) $A, B, C$ 를 4로 나눈 몫을 각각 $a, b, c \;(a < b < c)$ 라 할 때, $a, b, c$ 가 만족해야 하는 조건 3가지를 식으로 나타내시오. (5점)

(3) (2)에서 구한 각 순서쌍에 대해 $A \times C$ 의 값을 구하고, 어느 경우의 $A \times C$ 가 더 큰지 비교하시오. (5점)

문제 1 풀이

(1) $A = 4a, B = 4b, C = 4c$ 이므로 양변을 $4$ 로 나누면:
  • $a < b < c$ (자연수)
  • $a, b, c$ 의 최대공약수 $= 1$ (공약수 4를 빼낸 나머지는 서로소)
  • $a, b, c$ 의 최소공배수 $= 30 \;(= 120 \div 4)$
  • $a + b + c = 14 \;(= 56 \div 4)$
(2) $30$ 의 약수 $\{1, 2, 3, 5, 6, 10, 15, 30\}$ 중 세 개를 골라 위 조건을 모두 만족하는 조합:
$(a, b, c)$합최대공약수최소공배수판정
$(1, 3, 10)$$14$$1$$30$✓
$(3, 5, 6)$$14$$1$$30$✓
따라서 $(A, B, C) = (4, 12, 40)$ 또는 $(12, 20, 24)$
(3)
  • $(4, 12, 40)$: $A \times C = 4 \times 40 = 160$
  • $(12, 20, 24)$: $A \times C = 12 \times 24 = 288$
$(12, 20, 24)$ 의 경우가 더 크다.
⚡ 채점 포인트: 답이 2개라는 것을 빠짐없이 찾기. 하나만 쓰면 절반 감점.

문제 3 풀이

(1) 가운데 수가 $0$ 이므로 $S = 3 \times 0 = $ $0$
이유: 마방진 9칸 전체의 합은 $3S$ 이다 (가로 줄 3개의 합). 가운데 칸을 지나는 줄(가로·세로·대각선 2개) 4줄의 합은 $4S$ 인데, 이 4줄은 가운데 수를 4번, 나머지 8칸을 1번씩 포함한다. 즉 $4S = (\text{전체 9칸 합}) + 3 \times (\text{가운데}) = 3S + 3 \times (\text{가운데})$ 정리하면 $S = 3 \times (\text{가운데 수})$.
(2) $S = 0$ 이므로 각 줄의 합이 $0$.
순서사용 줄식결과
①대각선 ↘$-\frac{1}{2} + 0 + ? = 0$우하 = $\frac{1}{2}$
②대각선 ↙$\frac{1}{6} + 0 + ? = 0$좌하 = $-\frac{1}{6}$
③위 가로$-\frac{1}{2} + ? + \frac{1}{6} = 0$상중 = $\frac{1}{3}$
④왼 세로$-\frac{1}{2} + ? + (-\frac{1}{6}) = 0$좌중 = $\frac{2}{3}$
⑤오른 세로$\frac{1}{6} + ? + \frac{1}{2} = 0$우중 = $-\frac{2}{3}$
⑥아래 가로 검산$-\frac{1}{6} + (-\frac{1}{3}) + \frac{1}{2} = 0$ ✓—
완성된 마방진:
$-\dfrac{1}{2}$$\dfrac{1}{3}$$\dfrac{1}{6}$
$\dfrac{2}{3}$$0$$-\dfrac{2}{3}$
$-\dfrac{1}{6}$$-\dfrac{1}{3}$$\dfrac{1}{2}$
(3) 가장 큰 수 $\dfrac{2}{3}$, 가장 작은 수 $-\dfrac{2}{3}$. 차 $= \dfrac{2}{3} - \left( -\dfrac{2}{3} \right) = $ $\dfrac{4}{3}$
