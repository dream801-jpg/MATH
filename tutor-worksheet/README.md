# 다시풀기 · 나의 과외 문제지

ChatGPT·코덱스·Claude에서 문제를 만들고, 여기에서 선택·수정하여 A4로 출력하는 개인용 웹앱입니다.

**API Key를 넣을 필요가 없습니다. 앱은 AI를 호출하지 않습니다.** 사진과 요청문은 사용 중인 AI 대화에 직접 보내세요. AI 대화의 이용 한도와 요금은 해당 서비스의 이용 조건을 따릅니다. 문제 불러오기·도형 표시·출력은 브라우저 안에서 처리합니다.

## 가장 간단한 사용 방법

1. 이 폴더의 **start.cmd를 두 번 클릭**합니다. 실행 창을 켜두세요.
2. 브라우저에서 [http://localhost:3000](http://localhost:3000)을 엽니다.
3. ‘숫자만 변경 / 비슷한 유형 / 응용 문제’와 ‘3 / 5 / 10문제’를 고릅니다.
4. **AI에 보낼 요청문 복사**를 누릅니다.
5. 평소 쓰는 ChatGPT·코덱스·Claude에 문제 사진과 복사한 요청문을 보냅니다. 사진을 다룰 수 없는 환경이라면 문제를 글로 입력하세요.
6. AI가 준 JSON 전체를 이 앱의 입력 칸에 붙여넣고 **붙여넣은 문제 불러오기**를 누릅니다. AI가 파일로 만들었다면 **문제 파일 불러오기**를 사용하세요.
7. 문제와 정답·풀이를 확인하고 원하는 문제를 선택합니다.
8. **선택 문제로 문제지 만들기 → PDF 저장 또는 인쇄**를 누릅니다.

먼저 시험하려면 **예제 5문제로 먼저 써보기**를 누르세요. AI 대화 없이 문제지와 출력 화면을 살펴볼 수 있습니다. `examples/worksheet.json`도 바로 불러올 수 있는 예제 문제 파일입니다.

종료는 실행 창에서 `Ctrl+C`입니다. 3000번 포트가 이미 사용 중이면 창에 표시된 실제 주소를 여세요. 앱 자체에서 AI 대화를 자동으로 실행하거나 결과를 자동으로 가져오지는 않습니다.

## 직접 실행하거나 다른 PC에 설치하기

현재 PC에는 필요한 구성요소를 설치해 두었습니다. 다른 PC에서는 [Node.js LTS](https://nodejs.org/)를 설치한 뒤 이 폴더에서 아래 명령을 한 번 실행하세요. Next.js 16은 Node.js 20.9 이상이 필요합니다.

```powershell
npm install
npm run dev
```

이 Codex 환경처럼 npm을 찾지 못하면 제공된 pnpm으로 실행할 수 있습니다.

```powershell
cd "C:\Users\MAP2051\Desktop\윤드림 코드\tutor-worksheet"
$pnpmPath = "$env:USERPROFILE\.cache\codex-runtimes\codex-primary-runtime\dependencies\bin\fallback\pnpm.cmd"
& $pnpmPath install
& $pnpmPath dev
```

반복 사용 시에는 `start.cmd`만 실행하면 됩니다. 기존에 만들었던 `.env.local`이 있다면 이 버전에서는 사용하지 않습니다. 키를 새로 만들거나 입력할 필요가 없습니다.

## 휴대폰에서 사용하기

PC에서 앱을 켜고 휴대폰과 PC를 같은 공유기에 연결하세요. PC가 유선이어도 같은 공유기의 Wi-Fi면 됩니다. PowerShell에서 `ipconfig`로 IPv4 주소를 확인한 뒤 휴대폰 브라우저에서 `http://PC주소:3000`을 엽니다.

이 PC에서 확인한 주소는 [http://172.31.22.205:3000](http://172.31.22.205:3000)이었습니다. 주소는 바뀔 수 있습니다. 회사망이나 게스트 Wi-Fi에서는 기기 간 연결이 막힐 수 있습니다. Windows 방화벽은 개인 네트워크 허용 여부를 확인하고, 방화벽 전체를 끄지 마세요. 로그인 없는 개인용 도구이므로 인터넷에 공개하지 마세요.

휴대폰에서는 사진을 ChatGPT·Claude 등 사용 중인 AI에 직접 올립니다. AI 응답을 복사해 이 앱에 붙여넣거나, 받은 JSON 파일을 불러오면 됩니다. 보안 연결이 아닌 주소에서 자동 복사가 안 되면 **요청문 직접 복사**를 열고 길게 눌러 복사하세요.

## 파일로 저장하고 다른 기기에서 이어 쓰기

문제를 불러온 뒤 **문제 파일 저장**을 누르면 전체 문제·정답·풀이가 `worksheet.json`으로 저장됩니다. 저장한 파일을 PC나 휴대폰으로 보내 **문제 파일 불러오기**로 열면 됩니다.

새로고침하면 작업 내용이 사라집니다. 파일에는 전체 문제·도형·원문 정보를 저장하며 학생 이름·출력 날짜·선택 상태는 저장하지 않습니다. 다른 기기에서 열면 정답과 풀이를 확인하고 문제를 선택합니다. 기기 간 자동 공유는 없습니다.

## 정답 확인과 수정

행렬은 `[[0, 0], [6, 0]]`처럼 불러오면 화면과 문제지·정답지에서 행과 열이 정렬된 둥근 괄호 행렬로 표시됩니다. 이미 만든 행렬 문제 파일도 그대로 사용하세요. 편집 칸과 저장 파일은 원래의 대괄호 표기를 유지합니다. 숫자·문자 성분과 최대 6행·6열까지 지원하며, 행마다 성분 수가 다르거나 표기가 불완전하면 원문 그대로 보여줍니다. 행렬 모양 표시와 정답 자동 검증은 별개입니다.

분수·루트·지수·적분은 이제 수식 모양으로 표시합니다. 새 AI 요청문은 문장 속 수식을 `$...$`, 독립 수식을 `$$...$$`로 작성하도록 안내합니다. 수식 안에서는 LaTeX를 사용하며, JSON의 역슬래시는 두 번 적어야 합니다. 이전 파일의 명확한 일반 글자 적분·분수·지수도 표시 단계에서 변환합니다. 잘못된 수식은 원문으로 남기며 불러오기 안내에 알립니다. 긴 수식은 휴대폰에서 옆으로 밀어 볼 수 있습니다. 저장·편집용 원문은 유지됩니다.

원본 문제 아래에 **AI가 구한 원본 정답**이 표시됩니다. **원본 풀이 확인**을 열어 풀이도 볼 수 있습니다. 원본 정답지와 비교하세요. AI가 풀지 못했거나 확신이 없으면 추측하지 말고 이유를 알리도록 요청문에 반영했습니다. 이 기능은 정답을 보장하거나 자동 검산하지 않습니다.

원본에 도형이 있으면 유사문제에도 도형을 넣도록 요청문에 반영했습니다. 점·선분·원·다각형·음영·각도·직각 표시를 지원하며, 화면과 문제지에 함께 표시합니다. 방금 시험한 원·현 문제는 AB·AC 값에 맞는 그림이 나옵니다. 기존의 같은 유형 문제도 본문에서 길이를 읽어 그림을 표시할 수 있습니다. 곡선 함수 그래프·입체도형·이미지 직접 삽입은 아직 지원하지 않습니다.

- **정답·풀이 확인 후 선택:** 정답 자동 계산기는 사용하지 않습니다. AI가 만든 문제와 풀이를 확인한 뒤 ‘문제·정답을 확인하고 선택’을 체크하세요. 전체를 확인했다면 모두 선택 버튼을 사용할 수 있습니다.
- **문제 수정:** ‘문제·정답·풀이 수정’에서 고친 뒤 **수정 반영**을 누르세요. 도형의 조건도 살펴보고 다시 선택하세요. 일반 도형의 좌표까지 바꿔야 할 때는 AI에 새 도형을 포함해 다시 요청하세요.
- **필수 도형 누락 · 선택 불가:** 그림이 필요한 문제에 도형 정보가 빠진 경우입니다. AI에 도형을 포함한 결과를 다시 요청하세요. 정답 오류를 뜻하는 표시는 아닙니다.

공통 요청문에는 AI가 생성 후 각 문제를 다시 풀고 잘못된 문제를 수정하라는 지시가 들어 있습니다. 앱은 AI가 제공한 정답·풀이를 표시하며 이를 스스로 검산했다고 표시하지 않습니다. 별도 API 호출이나 자동 재생성은 실행하지 않습니다.

도형은 문제의 위치 관계를 보여주는 개략도입니다. 그림을 그리기 위한 좌표 계산과 정답 검산은 별개입니다. AI가 만든 일반 도형의 각도·접선·길이 관계도 인쇄 전에 확인하세요. `examples/circle-chord-worksheet.json`에 도형이 포함된 수능 유형 예제를 넣었습니다.

## PDF 저장과 인쇄

선택한 문제로 문제지를 만들고 학생 이름·날짜·단원·풀이 공간을 정하세요.

- **문제지만 PDF:** 정답 없이 출력합니다.
- **문제 + 정답 PDF:** 문제지 뒤의 새 페이지부터 정답과 해설을 출력합니다.
- **PDF 저장 / 인쇄:** ‘끝에 정답 및 해설 추가’ 체크에 따라 출력합니다.

PDF 버튼도 브라우저 인쇄 창을 엽니다. **대상: PDF로 저장 / 용지: A4 / 배율: 100% / 머리글·바닥글: 끄기**를 선택하세요. 인쇄하려면 대상을 실제 프린터로 바꾸세요. 긴 문제나 해설은 여러 페이지에 걸칠 수 있습니다.

저장한 PDF를 열어 한글·수식·문제 번호·풀이 공간·정답 포함 여부를 확인한 뒤 한 장 시험 출력하세요. 앱 안에서 인쇄 창이 열리지 않으면 일반 Chrome·Edge·Safari로 주소를 여세요. 휴대폰에서는 브라우저 메뉴의 공유·인쇄 기능도 사용할 수 있습니다.

## 불러올 수 있는 파일 형식

UTF-8 JSON 또는 JSON 내용이 든 TXT 파일, 최대 1MB·30문제를 지원합니다. AI가 JSON을 코드 블록으로 감싸도 한 개라면 읽을 수 있습니다. 원문 정보가 없는 문제 목록만 있어도 됩니다.

```json
{
  "original_problem": "3x + 5 = 20",
  "subject": "수학",
  "unit": "일차방정식",
  "generated_questions": [
    {
      "question": "다음 방정식을 푸시오. 4x + 7 = 31",
      "answer": "6",
      "solution": "4x = 24이므로 x = 6입니다."
    }
  ]
}
```

`generated_questions` 대신 `questions`도 지원합니다. 문제와 정답은 필수이며 항목당 6,000자까지입니다. 잘못된 내용을 불러와도 기존 문제는 지워지지 않습니다. 문제를 저장할 때는 유효한 JSON으로 저장하며 검증 표시는 포함하지 않습니다.

## 오류가 발생하면

| 증상 | 확인할 부분 |
| --- | --- |
| JSON을 읽지 못함 | AI 답변의 JSON 전체를 복사했는지 확인. 마지막 괄호나 쉼표가 빠졌다면 AI에 올바른 JSON으로 다시 작성 요청 |
| 문제 형식 오류 | 각 문제의 question·answer 항목 확인. 빈 목록과 30문제 초과는 불가 |
| 파일을 읽지 못함 | 사진이나 PDF 대신 JSON·TXT를 선택했는지, 1MB 이하인지 확인 |
| 요청문 복사가 안 됨 | ‘요청문 직접 복사’를 열어 수동 복사 |
| 문제를 선택할 수 없음 | 필수 도형이 빠졌는지 확인하고 AI에 도형 포함 결과를 다시 요청 |
| 수정 내용이 인쇄되지 않음 | ‘수정 반영’을 눌렀는지 확인 |
| 휴대폰에서 접속이 안 됨 | PC 서버 실행, IPv4 주소, 같은 네트워크, 포트와 방화벽 허용 확인 |
| 인쇄 창이 안 열림 | 일반 브라우저에서 열거나 브라우저 메뉴의 인쇄 사용 |
| start.cmd가 실행되지 않음 | Node.js 설치와 최초 npm install 여부 확인. 실행 창의 오류를 읽고 README의 직접 실행 방법 사용 |

## 구성과 확인 기록

Next.js·TypeScript로 만들었으며 화면과 인쇄 양식은 일반 CSS를 사용합니다. 데이터베이스·회원가입·API 연결·키 설정은 없습니다.

```text
app/page.tsx           요청문·가져오기·선택·수정·출력 화면
app/globals.css        PC·모바일 화면과 A4 인쇄 양식
lib/worksheet.ts       공통 요청문, 불러오기·저장, 도형 누락 확인
lib/diagram-schema.ts  도형 정보 확인과 그림 표시용 좌표
app/components/problem-diagram.tsx  화면·인쇄 공통 도형
lib/schema.ts          가져온 자료의 형식 확인
tests/                불러오기·도형·파일 왕복 검사
examples/worksheet.json  예제 문제 파일
start.cmd             Windows 실행 파일
```

개발 검사: `npm test`, `npm run typecheck`, `npm run build`. pnpm 사용자는 같은 명령을 `pnpm test` 등으로 실행합니다. 실제 프린터 출력과 실물 휴대폰의 파일 선택 동작은 사용하는 기기에서 확인하세요.

## 삼각함수 그래프

사인·코사인 곡선, 수평선, 교점 이름과 축을 화면과 문제지에 표시합니다. 새 AI 요청문에 그래프 작성 형식이 포함되어 있습니다. 이전 요청문으로 만든 파일에 그래프가 없으면 새 요청문으로 다시 요청하세요.

`examples/trigonometric-graph-worksheet.json` 또는 `worksheet.json`을 불러오면 첨부된 코사인 문제와 숫자를 바꾼 5문제를 볼 수 있습니다. 원본 정답은 ③ π/2입니다. 그래프의 가로·세로 배율은 다를 수 있습니다. 그림 표시용 좌표 계산은 정답 자동 검산과 별개입니다.

## 긴 문제의 출력 여백 줄이기

출력 준비 화면에서 **풀이 공간 → 없음 · 빈 공간 줄이기**를 선택하고 **출력할 글·수식 간격 줄이기**를 켜세요. 이미 불러온 문제에도 바로 적용됩니다. 긴 문제와 해설은 다음 장으로 이어지며, 정답지는 새 페이지에서 시작합니다. 글의 양이 많으면 여러 장이 되는 것은 정상입니다.

AI가 줄바꿈을 중복 기록하여 역슬래시와 n이 화면에 남는 경우 일반 문장만 자동으로 줄바꿈으로 복구합니다. 수식의 명령과 행렬 줄바꿈은 보존합니다. JSON 전체가 문자열로 한 번 더 감싸진 응답도 불러올 수 있습니다.

첨부받은 정적분 문제는 **긴 문제 인쇄 예제** 버튼에 넣었습니다. 인쇄 창에서 A4·배율 100%·머리글/바닥글 끄기로 먼저 확인하세요.

## 교사 확인·수업 조건

### 영역 색칠 그림

**영역 색칠 경우의 수** 예제를 누르면 곡선으로 나뉜 여섯 영역 그림과 색의 수를 바꾼 3문제가 열립니다. 경계를 공유하는 영역과 점 하나만 공유하는 영역을 구분합니다. 예제의 B–F와 C–E는 점만 공유합니다. 곡선 모양은 개략적으로 재구성했으며 원본의 이웃 관계는 유지했습니다.

새 수학 요청문에는 `region_map` 작성 형식이 들어 있습니다. AI는 꼭짓점·영역 이름·경계 양쪽 영역을 정의하고, 곡선에는 제어점 두 개를 넣습니다. 원본·문제 목록·A4 문제지·저장한 JSON에 같은 그림 정보를 사용합니다. 형식 검사는 경계가 닫혀 있는지와 참조 오류 등을 확인하지만 원본 사진의 해석·곡선 교차·라벨 위치·정답을 보장하지 않습니다. 수업에 쓰기 전에 그림의 이웃 관계를 직접 확인하세요. 구멍이 있는 영역이나 이 형식에 맞지 않는 그림은 AI가 먼저 알려주도록 했습니다.

도형·그래프가 있는 문제의 본문을 수정하면 **도형 재확인 필요**가 표시됩니다. 조건과 그림이 일치한다는 별도 확인 전에는 전체 선택에서도 제외됩니다. 그림을 고쳐야 하면 새 JSON을 불러오세요. 풀이가 비어 있거나 과거의 풀이 누락 안내문이면 **풀이 없음**으로 구분합니다. 교사가 별도로 허용한 경우만 선택할 수 있고, 해설지에 안내문이 들어간다는 사실을 출력 준비 화면에서도 보여줍니다. 문제 본문과 정답이 빈 파일은 불러오지 않습니다.

요청문 작성 시 **수업 조건과 연습 목적**을 열어 학년·배운 범위·허용 풀이 방법·틀린 이유를 선택 입력할 수 있습니다. 개념 연습은 개념 힌트와 자세한 해설, 실수 줄이기는 점검 지점과 확인 과정, 독립 풀이는 힌트 없이 핵심 근거를 요청합니다. 받은 hint는 접어서 보여주며 문제지 포함 여부를 별도로 고릅니다.

각 문제에서 풀이 공간과 **오답·재시험 대상**을 정하고 **오답 표시한 문제만 선택**으로 모을 수 있습니다. 오답 표시·풀이 공간·도형 재확인 필요 표시는 문제 파일에 보존하지만, 교사의 확인·선택·풀이 누락 허용 상태는 다시 불러올 때 초기화합니다. 영어는 타당하고 서로 다른 출제 지점이 부족하면 요청한 개수보다 적게 반환하고 이유를 쓰도록 했습니다. 내장 영어 예제는 서로 다른 빈칸 2곳과 어법 오류 1곳이며, 지문 전체 변경 예제가 아닙니다. 서술형·조건 영작과 자동 채점은 아직 제공하지 않습니다.

### 영어 선택 방법

요청문을 복사하기 전에 과목에서 **영어**를 선택하세요.

- **원문 유지:** 같은 지문 안의 다른 부분을 빈칸·어법·어휘 문제로 출제하도록 요청합니다. 기존 빈칸은 원본 정답으로 복원합니다. 오류 찾기 문제에서만 출제 부분 한 곳을 의도적으로 바꿉니다.
- **표현만 조금 변경:** 지문 전체를 다시 쓰지 않고 단어·짧은 표현을 1~3곳만 바꾸도록 요청합니다.

문제 유형은 기본값인 **원본 유형 유지**, 빈칸 추론·어법·문맥상 어휘·섞어서 출제 중 고릅니다. 원본 유형 유지는 문장삽입이면 다른 문장을 빼고, 빈칸이면 다른 부분을 비웁니다. 원래 문제는 정답으로 먼저 복원합니다. 삽입 문제에는 주어진 문장과 다섯 삽입 위치를 포함하고, 각 위치에 넣어 정답이 하나인지 검토하도록 요청합니다. 가능한 지점이 부족하면 무리하게 개수를 채우지 않도록 했습니다.

새 지문 작성은 제공하지 않습니다. 요청문에는 정답 근거, 다른 보기의 오답 이유, 출제 지점과 변경 표현을 해설에 밝히도록 넣었습니다. AI 결과가 실제로 원문을 유지하고 있는지는 정답·풀이와 함께 확인하세요. 앱은 영어 문제를 자동 생성하거나 정답을 보장하지 않습니다.
