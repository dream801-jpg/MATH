문제 1. 점, 선, 면 (20점)
(1) 오른쪽 그림과 같이 원 위에 여섯 개의 점 $\text{A, B, C, D, E, F}$ 가 있다. 이 중 두 점을 이어 만들 수 있는 서로 다른 직선의 개수를 $a$, 반직선의 개수를 $b$, 선분의 개수를 $c$ 라 할 때, $a + b + c$ 의 값을 구하시오. (6점)
(2) $\overline{\text{AB}}$ 위에 다음을 만족하는 세 점 $\text{M, N, P}$ 가 있다. $\overline{\text{NP}} = 14\,\text{cm}$ 일 때, $\overline{\text{AB}}$ 의 길이를 구하시오. (풀이 과정 서술) (7점)
· 점 $\text{M}$ 은 $\overline{\text{AB}}$ 의 중점, 점 $\text{N}$ 은 $\overline{\text{AM}}$ 의 중점이다.
· 점 $\text{P}$ 는 $\overline{\text{MB}}$ 위의 점이고, $\overline{\text{MP}} = 2\overline{\text{PB}}$ 이다.
(3) 서로 다른 네 직선이 한 점에서 만날 때 생기는 맞꼭지각은 모두 몇 쌍인지 구하고, 그렇게 구한 이유를 설명하시오. (7점)
문제 2. 위치관계 (20점)
다음 그림은 밑면이 정육각형이고 옆면이 모두 직사각형인 육각기둥이다. (단, 모서리의 위치관계는 모서리를 연장한 직선으로 생각한다.)
(1) 모서리 $\text{AB}$ 와 평행한 모서리를 모두 구하시오. (5점)
(2) 모서리 $\text{AB}$ 와 꼬인 위치에 있는 모서리의 개수를 구하시오. (단, 모서리 $\text{AB}$ 와 만나는 모서리, 평행한 모서리를 먼저 모두 찾아 쓸 것) (8점)
(3) 면 $\text{ABHG}$ 와 평행한 면을 구하시오. 또, 면 $\text{ABCDEF}$ 와 수직인 면의 개수를 구하시오. (7점)
문제 3. 삼각형의 작도 (20점)
다음 그림은 직선 $l$ 밖의 한 점 $\text{P}$ 를 지나고 직선 $l$ 에 평행한 직선을 작도한 것이다.
(1) 다음 작도 과정을 순서대로 나열하시오. (6점)
ㄱ. 점 $\text{P}$ 를 지나는 직선을 그어 직선 $l$ 과의 교점을 $\text{Q}$ 라 한다.
ㄴ. 점 $\text{C}$ 를 중심으로 반지름의 길이가 $\overline{\text{AB}}$ 인 원을 그려 ㅂ에서 그린 원과의 교점을 $\text{D}$ 라 한다.
ㄷ. 점 $\text{Q}$ 를 중심으로 원을 그려 직선 $l$, 직선 $\text{PQ}$ 와의 교점을 각각 $\text{A, B}$ 라 한다.
ㄹ. 두 점 $\text{P, D}$ 를 지나는 직선을 긋는다.
ㅁ. 컴퍼스로 $\overline{\text{AB}}$ 의 길이를 잰다.
ㅂ. 점 $\text{P}$ 를 중심으로 반지름의 길이가 $\overline{\text{QA}}$ 인 원을 그려 직선 $\text{PQ}$ 와의 교점을 $\text{C}$ 라 한다.
(2) 이 작도는 어떤 두 각의 크기가 같도록 한 것인지 쓰고, 이를 이용해 직선 $\text{PD}$ 와 직선 $l$ 이 평행한 이유를 설명하시오. (4점)
(3) 세 변의 길이가 $3\,\text{cm},\ 7\,\text{cm},\ x\,\text{cm}$ 인 삼각형과 세 변의 길이가 $x\,\text{cm},\ 4\,\text{cm},\ 9\,\text{cm}$ 인 삼각형을 모두 만들 수 있도록 하는 자연수 $x$ 의 값을 모두 구하시오. (풀이 과정 서술) (10점)
문제 4. 평행선의 성질 (20점)
(1) [그림 1]에서 $l \,/\!/\, m$ 이고 $\triangle\text{ABC}$ 는 정삼각형이다. 꼭짓점 $\text{A}$ 는 직선 $l$ 위에, 꼭짓점 $\text{B}$ 는 직선 $m$ 위에 있을 때, $\angle x$ 의 크기를 구하시오. (단, 보조선과 이용한 성질을 서술할 것) (8점)
(2) [그림 2]에서 $l \,/\!/\, m$ 이고, 한 직선이 $l, m$ 과 만나는 점을 각각 $\text{A, B}$ 라 하자. 두 직선 사이에서 직선 $\text{AB}$ 의 오른쪽에 생기는 $\angle\text{A}$ 와 $\angle\text{B}$ 의 이등분선의 교점을 $\text{P}$ 라 할 때, $\angle\text{APB}$ 의 크기를 구하고 그 이유를 설명하시오. (12점)
문제 5. 삼각형의 합동 (20점)
(1) [그림 1]은 $\angle\text{XOY}$ 의 이등분선을 작도한 것이다. 점 $\text{O}$ 를 중심으로 원을 그려 두 변과 만나는 점을 $\text{A, B}$ 라 하고, 두 점 $\text{A, B}$ 를 중심으로 반지름의 길이가 같은 원을 그려 만나는 점을 $\text{P}$ 라 하였다. $\triangle\text{AOP} \equiv \triangle\text{BOP}$ 임을 설명하고, 이를 이용하여 $\overrightarrow{\text{OP}}$ 가 $\angle\text{XOY}$ 의 이등분선이 되는 이유를 쓰시오. (10점)
(2) [그림 2]와 같이 강의 폭 $\overline{\text{AB}}$ 를 직접 재지 않고 구하기 위해 네 점 $\text{B, C, D, E}$ 를 잡았다. $\angle\text{ABC} = \angle\text{EDC} = 90^\circ$, $\overline{\text{BC}} = \overline{\text{DC}}$ 이고 세 점 $\text{A, C, E}$ 는 한 직선 위에 있다. $\overline{\text{DE}} = 38\,\text{m}$ 일 때, 강의 폭 $\overline{\text{AB}}$ 를 구하고 그 이유를 합동 조건을 이용하여 설명하시오. (10점)

문제 1 풀이

(1) 원 위의 점은 어느 세 점도 한 직선 위에 있지 않으므로, 두 점을 고르는 방법마다 서로 다른 직선·선분이 생긴다.
  • 두 점을 고르는 방법: $\dfrac{6 \times 5}{2} = 15$ → 직선 $a = 15$, 선분 $c = 15$
  • 반직선은 시작점이 다르면 다르므로 $6 \times 5 = 30$ → $b = 30$
$a + b + c = 15 + 30 + 15 = $ $60$
(2) $\overline{\text{AB}} = x$ 라 하면
  • $\overline{\text{AM}} = \overline{\text{MB}} = \dfrac{1}{2}x$,   $\overline{\text{NM}} = \dfrac{1}{2}\overline{\text{AM}} = \dfrac{1}{4}x$
  • $\overline{\text{MP}} = 2\overline{\text{PB}}$ 이므로 $\overline{\text{MP}} = \dfrac{2}{3}\overline{\text{MB}} = \dfrac{2}{3} \times \dfrac{1}{2}x = \dfrac{1}{3}x$
$\overline{\text{NP}} = \overline{\text{NM}} + \overline{\text{MP}} = \dfrac{1}{4}x + \dfrac{1}{3}x = \dfrac{7}{12}x = 14$ → $x = 24$    $\overline{\text{AB}} = 24\,\text{cm}$
(3) 두 직선이 한 점에서 만나면 맞꼭지각이 $2$ 쌍 생긴다. 네 직선 중 두 직선을 고르는 방법은 $\dfrac{4 \times 3}{2} = 6$ 가지이고, 각 경우마다 $2$ 쌍씩 생기므로 $6 \times 2 = $ $12$ 쌍
⚡ 채점 포인트: (2) $\overline{\text{MP}} = 2\overline{\text{PB}}$ 를 "$\overline{\text{MB}}$ 를 $3$ 등분한 것 중 $2$ 개"로 바꾸는 과정이 핵심. (3) 이웃한 각끼리 묶은 큰 각의 맞꼭지각도 세야 하므로, 작은 각 $8$ 개만 보고 $4$ 쌍이라 쓰면 오답.

문제 2 풀이

(1) 정육각형에서 $\overline{\text{AB}} \,/\!/\, \overline{\text{DE}}$ 이고, 아랫면에서는 $\overline{\text{GH}}$ 와 $\overline{\text{JK}}$ 가 이에 대응 → $\overline{\text{DE}},\ \overline{\text{GH}},\ \overline{\text{JK}}$
(2) 모서리는 모두 $6 + 6 + 6 = 18$ 개
  • 만나는 모서리: $\text{BC, FA, AG, BH}$ 그리고 연장하면 만나는 $\text{CD, EF}$ → $6$ 개
  • 평행한 모서리: $\text{DE, GH, JK}$ → $3$ 개
꼬인 위치: $18 - 1 - 6 - 3 = 8$ → $8$ 개 ($\text{HI, IJ, KL, LG, CI, DJ, EK, FL}$)
(3) 면 $\text{ABHG}$ 와 평행한 면: 면 $\text{DEKJ}$
면 $\text{ABCDEF}$ 와 수직인 면: 옆면 $6$ 개 → $6$ 개
⚡ 채점 포인트: (2)의 함정 — 정육각형의 변 $\text{CD}$, $\text{EF}$ 는 $\text{AB}$ 와 닿지 않지만 연장하면 만난다(같은 평면 위, 평행 아님). 이걸 꼬인 위치로 세면 $10$ 개로 오답.

문제 3 풀이

(1) ㄱ → ㄷ → ㅂ → ㅁ → ㄴ → ㄹ
(2) $\angle\text{AQB}$ 와 크기가 같은 $\angle\text{DPC}$ 를 작도한 것이다. 이 두 각은 직선 $\text{PQ}$ 가 두 직선 $l$, $\text{PD}$ 와 만날 때 생기는 동위각이다. → 동위각의 크기가 같으므로 $\text{PD} \,/\!/\, l$
(3) 삼각형이 되는 조건: (나머지 두 변의 길이의 차) $<$ (한 변) $<$ (나머지 두 변의 길이의 합)으로 생각해도 되고, 가장 긴 변으로 나누어도 된다.
  • $3, 7, x$: $7 - 3 < x < 7 + 3$ → $4 < x < 10$ → $x = 5, 6, 7, 8, 9$
  • $x, 4, 9$: $9 - 4 < x < 9 + 4$ → $5 < x < 13$ → $x = 6, 7, \cdots, 12$
둘 다 만족: $x = 6, 7, 8, 9$
⚡ 채점 포인트: (2) "엇각"이 아니라 동위각. 판정 문장 "동위각의 크기가 같으면 두 직선은 평행하다"까지 써야 만점. (3) 두 조건의 공통 범위를 구해야 함. $x = 5$ 는 두 번째 삼각형에서 $9 = 5 + 4$ 라 안 됨.

문제 4 풀이

(1) 점 $\text{C}$ 를 지나고 $l$ 에 평행한 직선 $n$ 을 긋는다. ($l \,/\!/\, n \,/\!/\, m$)
  • $\angle\text{ACB} = 60^\circ$ 를 $n$ 이 위·아래로 나눈다.
  • 위쪽 각 $= 20^\circ$ ($l$ 과의 엇각), 아래쪽 각 $= \angle x$ ($m$ 과의 엇각)
$20^\circ + \angle x = 60^\circ$ → $\angle x = 40^\circ$
(2)
  • 점 $\text{A}$ 에서 직선 $\text{AB}$ 의 오른쪽 아래 각을 $\angle a$ 라 하면, 점 $\text{B}$ 에서 직선 $\text{AB}$ 의 왼쪽 위 각도 $\angle a$ (엇각)
  • 점 $\text{B}$ 에서 왼쪽 위 각과 오른쪽 위 각의 합은 $180^\circ$ (평각) → $\angle\text{A} + \angle\text{B} = 180^\circ$
  • $\angle\text{PAB} + \angle\text{PBA} = \dfrac{1}{2}(\angle\text{A} + \angle\text{B}) = 90^\circ$
  • $\triangle\text{APB}$ 에서 $\angle\text{APB} = 180^\circ - 90^\circ = $ $90^\circ$
⚡ 채점 포인트: (2) 핵심은 "평행선 사이에서 같은 쪽에 있는 두 각의 합이 $180^\circ$" — 이것을 엇각 + 평각으로 이유까지 써야 만점. 그림을 재서 $90^\circ$ 라고만 쓰면 점수 없음.

문제 5 풀이

(1) $\triangle\text{AOP}$ 와 $\triangle\text{BOP}$ 에서
  • $\overline{\text{OA}} = \overline{\text{OB}}$ (점 $\text{O}$ 를 중심으로 그린 같은 원의 반지름) ····· ①
  • $\overline{\text{AP}} = \overline{\text{BP}}$ (같은 반지름으로 그린 원) ····· ②
  • $\overline{\text{OP}}$ 는 공통 ····· ③
①, ②, ③에 의해 $\triangle\text{AOP} \equiv \triangle\text{BOP}$ (SSS 합동)
합동인 도형의 대응각은 같으므로 $\angle\text{AOP} = \angle\text{BOP}$ → $\overrightarrow{\text{OP}}$ 는 $\angle\text{XOY}$ 의 이등분선이다.
(2) $\triangle\text{ABC}$ 와 $\triangle\text{EDC}$ 에서
  • $\overline{\text{BC}} = \overline{\text{DC}}$ ····· ①
  • $\angle\text{ABC} = \angle\text{EDC} = 90^\circ$ ····· ②
  • $\angle\text{ACB} = \angle\text{ECD}$ (맞꼭지각) ····· ③
①, ②, ③에 의해 $\triangle\text{ABC} \equiv \triangle\text{EDC}$ (ASA 합동)이므로 $\overline{\text{AB}} = \overline{\text{ED}} = 38\,\text{m}$
⚡ 채점 포인트: (1) 작도에서 같은 길이가 나온 이유(같은 원의 반지름)를 써야 함. (2) ③(맞꼭지각)을 빠뜨리면 한 변과 한 각만 남아 합동 조건이 부족함 — 변 $\overline{\text{BC}}$ 의 양 끝각 $\angle\text{B}, \angle\text{C}$ 를 쓴 ASA임을 분명히.
